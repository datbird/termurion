FLAGS FOR ROBERT (decisions that differ from iTerm2 or that only he can make):
1. Tandem never fills a saved password silently. A saved password only prefills the sign-in prompt or is picked in the manager; the person always picks or presses OK (iTerm2 supplies a saved Basic credential without asking). Cost: one click each time. (The engine's own reuse of a sign-in already typed in this run is flag 14.)
2. http sites never get saved passwords: no lookup, nothing offered to remember, the manager lists nothing on http; a Basic challenge over http is warned about in the prompt.
3. Windows integrated sign-in (NTLM, Kerberos/Negotiate) is never sent automatically to a SITE (R13x710-1, proven by the probe). Intranet single sign-on sites will prompt or fail instead of signing in by themselves. NOT closed for PROXIES: a proxy (the one Tandem is told to use, or a system/WPAD one) that asks for NTLM or Negotiate gets the Windows sign-in exchange without a question, as Edge does; no WebView2 argument removes it (--auth-schemes is ignored), only machine-wide policy or proxy settings could. Your call whether that is acceptable.
4. A proxy configured (BrowserProxyEnabled) = no saved proxy passwords and no credential lookups or remembering for any site while it is on (R13x710-2); the proxy sign-in is typed each session.
5. A manager opened by a page's key button has no keyboard pick: arrows, Home, End, Page keys and Escape only, no Return, and no typing in its search field (R13x77-3). Pick by click or tap.
6. The autofill question answers Fill to a click or tap only; Escape is its only key; a keyboard-only person cannot fill from it.
7. Iframe and cross-origin fills are refused; autofill and password writes are main frame, https only (autofill also refuses http).
8. Accounts are matched to a page by exact https origin only (account_matches): an account saved for another site, a subdomain or an http address is hidden, and a Unicode host never matches (store it in punycode).
9. The card is Tandem's own (no macOS Contacts), DPAPI-protected and never exported; the first fill asks you to type it.
10. A password cannot be forced into a non-password field (no "fill it anyway").
11. Cancelling a sign-in silences that origin for 60 s, and switching tabs during a sign-in cancels it.
12. Residuals: secrets are wiped in Tandem's own buffers; WebView2, the DevTools pipe, the renderer and egui hold further copies Tandem cannot wipe; the "visible field" test is a heuristic; the target field is not re-checked at write time (only the approved types go to the approved origin).
13. The eight copied iTerm2 scripts and their GPL-2.0 text are PROVISIONAL (ruling Q5): your call before a public release.
