FLAGS FOR ROBERT: security rulings beyond iTerm2 (iTerm2 does none of these; each is a safe-side difference to accept or relax).
Flag 1. Sealed launch-state approvals. A stored "I approved these commands" counts only from Tandem's own launch state, as HMAC-SHA256 under a per-install 32-byte key (workgroup_restore::seal). The key file is workgroup-approval-key beside the settings, owner-only, protected with DPAPI (CurrentUser scope, Tandem's own entropy), never in settings.toml, never exported, never synced. Delete it, copy a state file from another install or user, or tamper with it, and every restore asks again. iTerm2 trusts what a saved window holds. Cost if wrong: one more question after a reinstall or a lost key.
Flag 2. Named arrangements always ask. A named arrangement never carries an approval (remote prefs can deliver a workgroup plus an arrangement plus open-at-startup, and the digest is computable); opening one restores the shown and buried members only after the person answers. iTerm2 restores unasked. Cost if wrong: an extra question per arrangement open that holds an imported workgroup.
Flag 3. Import All refuses aliased names. An archive holding, at any depth, a name Windows aliases (trailing dot or space, a ":" stream, a device name, a control character, an 8.3 short name "~N") is refused whole, at staging and again at the next start; export applies the same rule, hidden and excluded names are skipped (NTFS case fold), and the final path is checked. iTerm2 imports what it is given. Cost if wrong: an odd but harmless archive must be cleaned by hand.
Flag 4. Launched git refuses program-running repo config. Every git a workgroup starts in a pane goes through git_state::launch (no pager, hooks, external diff, textconv, credential helper, askpass, ssh program, transports, submodule recursion, no signature check with gpg programs pointed at nothing); a repo config key that names a program (the Chat peer's agent can write .git/config) refuses the launch; git templates with their own global options or other subcommands are refused, and a Regular member whose command is git does not start. iTerm2 uses libgit2 and runs none of it. Cost if wrong: a repository with such a key (diff.<d>.cachetextconv) cannot have git launched until the key goes.
Flag 5. Auto-send only to a known coding agent. The review text is pasted and submitted only to claude, codex, aider, gemini, opencode, goose, cursor-agent, copilot, qwen, amp or crush (image name, or the script, package or -m module a runtime runs), only the same agent process the review began under, never to a shell prompt or a transport (wsl, ssh). iTerm2 pastes into the main session. Cost if wrong: an agent not in the list gets no auto-send.
Residual 1 (accepted). Replay of this install's own earlier launch state: an Import All of an earlier export of this same install brings its state folder back, and an approval the person gave here for exactly those commands can restore. There is no revocation; a later "no" does not cancel an older state file's seal. It never changes a command, only whether it is asked again.
Residual 2 (accepted). Malware running as the person can read the DPAPI key (and any file the person owns). The key stops a copied file or another user, not code running as the same user.
