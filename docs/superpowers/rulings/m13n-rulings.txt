Task 1 (B2): a pane's cell is read from a warm table (`App::pane_faces`, one per window, swapped with the window), filled by `App::ensure_faces` at the top of every frame, in `apply_fonts`, in `relayout` and before a new pane is sized (`App::profile_cell` measures the new pane's face). `pane_cell` only reads and falls back to the tab's focused pane, then the default cell. `Renderer::resolve_family` and `has_family` are memoized, so no frame and no pointer move scans the installed fonts. Cost if wrong: a pane would open at the default grid and be resized on its first frame.
Task 1 (B3): a face carries the font's own cell (`base`), the spacing cell, the underline numbers and the baseline; the cursor geometry, the IME rectangle, 13l's underline numbers and `gapped_underlines` read the pane's face. A scale change re-measures every face in place (`Renderer::set_scale`, same ids, sizes rounded to 1/64 pixel so the keys the app builds at the new scale find them) and never clears the table; the table holds at most 512 faces, past which a new key gets the nearest existing size of its family. Cost if wrong: ids held in a Reduce Flicker slice or a queued row would name another face after a DPI change.
Task 1: each pane draws with its own profile's fonts through renderer faces; window chrome (tab bar, banners, toolbelt, status bar, title bars, clippings, inline chat panels, find bar, toasts) keeps the default profile's face and `App::cell`. Rows a pane's draw iteration makes after its badge (composer, completion list, info bar, portholes, signs, attention, blocks) take the pane's face and are laid out in the pane's cell; the badge sizes itself in pixels against the default font and keeps the default face. Cost if wrong: none known (iTerm2 draws every session with its own font table).
Task 1: `FaceKey.profile_bits` stays 0 until Task 3 to 5 pack the profile's drawing switches into it. Cost if wrong: none.
Task 1: the "Font not installed" banner still names the default profile's fonts only; a pane whose own profile names a missing font draws with the fallback and shows no banner. Cost if wrong: a missing font in a non-default profile is silent.
Task 1: `size_window` and a new window's first sizing keep the default cell, while snapping, Resize Window, the API's grid size and the tmux size report use the focused (or named) pane's cell (P13, P14). Cost if wrong: an edge snap in a window with two fonts steps by the focused pane's cell, not the other's.
R3: line height comes from the font's ascent, descent and leading (was: 1.2 times the size). The height is ceil(ascent + descent + leading), or ceil(ceil(ascent) + ceil(descent) + leading) for a family in FontsForGenerousRounding (default "consolas"), then ceil of height times Vertical Spacing; the width is the unrounded advance of one shaped "W" times Horizontal Spacing.
Task 2: the cell width stays the unrounded shaped advance of "W" (iTerm2 rounds it). Cost if wrong: a cell may be a fraction of a pixel narrower than iTerm2's.
Task 2 (P9): cosmic-text centers the glyphs in the line and has no baseline setter, so `fonts::baseline` only fills the underline baseline (the same centering); glyph placement is cosmic-text's own. Cost if wrong: glyphs sit up to half a pixel off iTerm2's baseline in a row that uses a fallback font.
Task 2: a changed FontsForGenerousRounding re-measures every face in place (`Renderer::set_generous_list`, read in `apply_fonts`). Cost if wrong: none.

Task 3 (bold and italic faces)
- Decision: a face stores the bold weight chosen by fonts::bold_weight over the weights of its family's regular-style faces (a variable face counts every 100-step of its wght range), with MinimumWeightDifferenceForBoldFont read when faces are built and re-applied in place on a change. Cost if wrong: a family with unusual weights may pick a different bold than on macOS.
- Decision: Use Bold Font and Use Italic Font are plain fields of FaceKey and of the per-pane RawFont cache (a face that ignores a switch is its own face). Cost if wrong: none.
- Decision: only spans pane_with marks fake_bold (terminal bold cells) follow Use Bold Font, the bold weight and the double strike; chrome, prose, icon, badge and toolbelt spans keep Weight::BOLD (P11 without a TextRow.terminal field). Cost if wrong: a pane-owned non-cell row (composer, info bar) keeps bold when Use Bold Font is off.
- Decision: the double strike is a second TextRow per row, appended after frame.rows (so underline gap indexes are unchanged and the copy never takes part in gaps), one physical pixel right, carrying only the bold spans; every other span is blank advance by character width. Cost if wrong: none known.

Task 4 (ligatures)
R3: ligatures form only with ASCII Ligatures or Non-ASCII Ligatures on (was: whatever the font does by default). Observed on EXTREME with Cascadia Code by a headless shaping test (glyph ids; Cascadia keeps two glyphs per pair, so a count of 1 never shows a ligature): with no features "->" shapes to ids [842, 1437] and "!=" to [812, 1774], ligated; features(2) gives the same ids; features(1) and features(0) give [765, 909] and [739, 907], the unjoined glyphs. Cost if wrong: none.
Task 4: the level of a font comes from the PostScript name of the family's regular face (blacklist, once per family) and EnableContextualAlternates; a Non-ASCII Font has its own level. Cost if wrong: a font whose PostScript name hides its family keeps ligatures on or off wrongly.
Task 4: cosmic-text shapes a word with the features of its first span (Attrs::compatible ignores them), so the renderer draws a row whose spans differ in ligature level as one row per run, each at its cell (Renderer::split_levels); pane_with also ends the piece at a color, bold, italic, cursor or selection change when either side ligates (iTerm2 builds its string per color). Cost if wrong: a mixed row costs one buffer per run (a ligature profile shapes more rows).
Task 4 (P7): with Non-ASCII Ligatures on, consecutive one-column non-ASCII cells share a piece; wide characters, emoji and a cell carrying a bidi control keep their own piece. Cost if wrong: Nerd Font sequences do not join, or a bidi control joins a run.
Task 4: terminal text at level 0 turns liga, clig, calt and dlig off only for ASCII text; non-ASCII text at level 0 keeps the shaper's features (it is one cell per piece, or a cursive run that must keep its forms). Cost if wrong: a font that ligates a single non-ASCII cell with its own marks keeps doing so.
