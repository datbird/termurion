Cost if wrong: ids held in a Reduce Flicker slice or a queued row would name another face after a DPI change.

Task 3 (bold and italic faces)
- Decision: a face stores the bold weight chosen by fonts::bold_weight over the weights of its family's regular-style faces (a variable face counts every 100-step of its wght range), with MinimumWeightDifferenceForBoldFont read when faces are built and re-applied in place on a change. Cost if wrong: a family with unusual weights may pick a different bold than on macOS.
- Decision: Use Bold Font and Use Italic Font are plain fields of FaceKey and of the per-pane RawFont cache (a face that ignores a switch is its own face). Cost if wrong: none.
- Decision: only spans pane_with marks fake_bold (terminal bold cells) follow Use Bold Font, the bold weight and the double strike; chrome, prose, icon, badge and toolbelt spans keep Weight::BOLD (P11 without a TextRow.terminal field). Cost if wrong: a pane-owned non-cell row (composer, info bar) keeps bold when Use Bold Font is off.
- Decision: the double strike is a second TextRow per row, appended after frame.rows (so underline gap indexes are unchanged and the copy never takes part in gaps), one physical pixel right, carrying only the bold spans; every other span is blank advance by character width. Cost if wrong: none known.

Task 4 (ligatures)
R3: ligatures form only with ASCII Ligatures or Non-ASCII Ligatures on (was: whatever the font does by default). Observed on EXTREME with Cascadia Code by a headless shaping test (glyph ids; Cascadia keeps two glyphs per pair, so a count of 1 never shows a ligature): with no features "->" shapes to ids [842, 1437] and "!=" to [812, 1774], ligated; features(2) gives the same ids; features(1) and features(0) give [765, 909] and [739, 907], the unjoined glyphs. Cost if wrong: none.
Task 4: the level of a font comes from the PostScript name of the family's regular face (blacklist, once per family) and EnableContextualAlternates; a Non-ASCII Font has its own level. Cost if wrong: a font whose PostScript name hides its family keeps ligatures on or off wrongly.
Task 4: cosmic-text shapes a word with the features of its first span (Attrs::compatible ignores them), so the renderer draws a row whose spans differ in ligature level as one row per run, each at its cell (Renderer::split_levels); pane_with also ends the piece at a color, bold, italic, cursor or selection change when either side ligates (iTerm2 builds its string per color). Cost if wrong: a mixed row costs one buffer per run (a ligature profile shapes more rows).
Task 4 (P7): with Non-ASCII Ligatures on, consecutive one-column non-ASCII cells share a piece; wide characters, emoji and a cell carrying a bidi control keep their own piece. Cost if wrong: Nerd Font sequences do not join, or a bidi control joins a run.
Task 4: terminal text at level 0 turns liga, clig, calt and dlig off only for ASCII text; non-ASCII text at level 0 keeps the shaper's features (it is one cell per piece, or a cursive run that must keep its forms). Cost if wrong: a font that ligates a single non-ASCII cell with its own marks keeps doing so.

Task 5 (anti-aliasing and thin strokes)
Live check (headless, an offscreen draw of "W" in Consolas at 16 px on EXTREME, before any behavior change): AA TODAY: distinct alpha levels=51, so text was always smoothed whatever the profile said. R3 note: this is not a default mismatch for the stock profile (it seeds both anti-alias switches on); the gap fixed here is that a profile with them off still smoothed. The filtered Aliased "W" has exactly the levels 0 and 255.
- Decision: a span's mask mode rides in its glyph cache key flags (bit 8 aliased with PIXEL_FONT, bit 9 thin) and is filtered in the vendored glyphon at both rasterization sites (first upload and atlas growth); hinting stays on. Cost if wrong: one more vendored crate to re-patch on updates; thin strokes look lighter but not like macOS font smoothing.
- Decision: "Retina" is scale >= 2.0 and a dark background is the pane palette's perceived brightness (HSP) below 0.5, read once per pane_with call. Cost if wrong: a background near the 0.5 line flips Thin Strokes on dark backgrounds one shade early or late.
- Decision: the face key packs the profile's ASCII Anti Aliased, Non-ASCII Anti Aliased and Thin Strokes (and RawFont mirrors them); the scale factor is already in the key through its pixel size and in RawFont, and ForceAntialiasingOnRetina is read per frame from the globals. Cost if wrong: none.
- Decision: the double strike shift follows iTerm2 (iTermTextDrawingHelper.m:2340 and :2661): an anti-aliased span shifts 0.5 point on a Retina-class scale (0.5 * scale pixels) and not at all below it (the second copy darkens the strokes in place); an aliased span shifts one physical pixel. A row mixing both gets one copy per shift. Cost if wrong: fake bold is thinner at 1x anti-aliased, as in iTerm2.
- Decision: glyphon's atlas-growth path skips a glyph that no longer rasterizes instead of unwrapping (a font that fails to load no longer panics there). Cost if wrong: such a glyph draws blank after a growth.

Task 7 (built-in Powerline glyphs)
- Decision: every Powerline shape is hand-written in src/powerline.rs from its geometry (polygons, strokes, curves); nothing is read from iTerm2's images or the PowerlineExtraSymbols files (ruling 13m-o). The flames, waves, lego blocks, rings, pixel squares and the branch, padlock and LN symbols are close to, not identical with, the originals. Cost if wrong: a symbol differs in detail from iTerm2's.
- Decision: the core set wins over the extended table, as iTerm2 asks isPowerlineGlyph first: U+E0B0 and U+E0B2 are the core arrowheads whatever SupportPowerlineExtendedSymbols says; U+E0B9 to U+E0BF are iTerm2's component strings (the box drawing path language), drawn by the box pipeline's own rasterizer. Cost if wrong: none.
- Decision: the mask depends on the code point, the size and the scale only (the extended switch decides which code points are drawn, not how); a wide symbol is rasterized into a box twice the cell wide, a half-width one (U+E0D2, U+E0D4) squeezes into half of that box, mirrored about the box first, so U+E0D4 inks the right cell, as iTerm2's transforms do. Cost if wrong: none.
- Decision: bleed is one device pixel at 1x (iTerm2's one point) times the scale, drawn inside the image transform, so a mirrored symbol bleeds on the other side. Cost if wrong: a seam of one pixel on a mirrored separator.
- Decision: a wide Powerline symbol is one CellGlyph two cells wide; the grid keeps one cell, the next cell's text still lays out at its own column and the glyph draws over it (iTerm2 does the same). On a right-to-left row the glyph sits at its cell's visual column and extends to the right. Cost if wrong: none known.
- Decision: Draw Powerline Glyphs is part of the face key and RawFont (a face that ignores the switch is another face); DisableCustomBoxDrawing turns the Powerline set off with the box set (iTerm2's sets are both empty with it). Cost if wrong: none.
