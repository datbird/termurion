UI parity sweep, package W: windows and alerts. Source of truth: the iTerm2 reference sources (file:line named in each guard row, src/win_texts.rs, and in the comments of each constant). "Crash logs from Apple" became "Crash logs from Microsoft"; the log note says "what PC you are using" and no settings are sent; the username in the template is the Windows user name from the environment. Send opens a new GitHub issue (the URL is cut at 7,000 characters with a note in the body). iTerm2 e-mails the developers; Windows has no mail path, so the issue is the Windows answer.
