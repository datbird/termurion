T1-1: Decision: no selector is still Later(12) after revealCockpit: moves to DONE, so a_chord_for_a_later_milestone_stays_with_windows lost its Cockpit assertion and keeps the Win+T check only - cost if wrong: a later milestone-12 item has no test of its own.
T1-2: Decision (P18): the Cockpit registers with the key hook through its own list (winkeys::add_cockpit_window, cockpit_chord: Alt+Win+Shift+C and nothing else), not CHAT_WINDOWS, because chat_chord takes only the chat window's chords and would leave the shortcut dead while the Cockpit has focus - cost if wrong: none.
T1-3: Decision: the frame is stored in physical pixels (outer top left, content size) and SIZE is read as pixels, so a first open on a high-DPI display is smaller than iTerm2's points - cost if wrong: a small first-open window until it is resized once.
T1-4: Decision: a show_and_focus is not undone by cockpit_follows_app for 600 ms, because the focus moves over a few passes and tandem_in_front() would otherwise hide the window it just opened - cost if wrong: the window stays up 600 ms after the last Tandem window loses the front.
T1-5: Decision: the frame and split are written to the settings file at most once a second (a pending write is flushed when the window closes); GROUP_KEY is read at launch into view.mode and written by Task 3's toolbar - cost if wrong: a crash within a second of a drag loses the last move.
T1-6: Decision: place() keeps a saved frame when its top left 40 by 40 lies inside any work area; a frame larger than the area it sits on is shrunk to the area and moved inside it - cost if wrong: none.
