m13x-webview2 rulings (appended as tasks land)

Task 3 popovers
- CSP: popover HTML keeps script-src 'unsafe-inline'. iTerm2 runs popover script (the bridge is only useful when page script can call it); the bridge reaches only the built-in functions and the RPCs the page's own API script already has. Cost if wrong: HTML a script author injects into a popover can call those functions. Hardened: no network (CSP), no WebRTC (WEBRTC_OFF_JS runs first in every frame), no DNS prefetch (meta), no navigation, closed bridge message set, 20 calls per second.
- Popover source (P6): the bridge trusts the first source the view reports when it is a data: or an about:blank document, ignoring a #fragment; an about:blank first source may be replaced by one data: source; any other source ends the trust. The value a real runtime reports is printed by the ignored test popover_source_is_recorded (scripts/xt test --lib web_popover -- --ignored --nocapture, interactive session). Not recorded yet: EXTREME over SSH is session 0. Expected: data:text/html;charset=utf-8,... (Chromium reports the data URL it loaded); the code accepts about:blank as well. Checklist row: run the ignored test once in the desktop session and paste its RECORDED line here.
- A link a person clicks in a popover is refused by the view (Event::Refused) and opened only through guard_open (external_uri_run, user gesture only); Open in and the no-runtime Quick Look fallback use the same judge.
- Superseded (Task 3 fix round 2 and Task 4 class ruling, see "Ledger rulings" below): the data:/about:blank source rule is replaced by an exact-URL check on a served document, and the script-src 'unsafe-inline' of the popover policy is now a response header on Tandem's own random origin, not a meta tag.

Pre-flight fixes (preflight.md, all accepted by the controller)

Ruling: B1 (loader). The first rule (load a pinned WebView2Loader.dll by full path) was dropped after Task 1 found that webview2-com-sys 0.39.1 on MSVC links WebView2LoaderStatic.lib; see "Static loader" below. What stays: scrub_env, a missing runtime is Runtime::Missing and never a failed launch, and a source test pins that no bare loader load exists - cost if wrong: none.
Ruling: B2 (BrowserPluginPathHint). The hint is used only when it is absolute, has no control character, is at most 260 characters (bounded at the Globals write point, stored empty when longer), passes LocalPath::judge (no share, no mapped drive, no link), is a directory and not a reparse point, is owned by the person, Administrators or TrustedInstaller with no write for anyone else, holds msedgewebview2.exe and msedge.dll, and msedgewebview2.exe carries a valid Microsoft Authenticode signature (WinVerifyTrust plus the signer name; the check and the launch are not atomic, accepted). A refused hint shows one banner naming the reason and the runtime is treated as missing (no silent fall back to Evergreen) - cost if wrong: a portable runtime in a user-writable folder or on a share is refused until its permissions are fixed.
Ruling: B3 (XSS in the copied local pages). The three copied iTerm2 scripts lose every inline handler built from data: data-url and data-id attributes are escaped with ONE escapeAttr (& < > " ' all five) and click listeners are added after the markup is built; every iterm2-about: response carries a strict policy (see "Local pages" below) plus nosniff and no-store; the Rust side distrusts the page (64 KiB, 8192 per string, closed set of actions per page, navigateToURL only to a URL already in the database with scheme http, https or about:blank, deleteEntry takes a uuid, clearAllHistory only from the history page's own source) - cost if wrong: these few lines differ from iTerm2's files, so a later cp of iTerm2's pages must redo the edit.
Ruling: B4 (navigation). One pure verdict (nav_verdict, then navigation_allowed with file_ok) judges every navigation of every view: a file: target that is not local (a host other than empty or localhost, a remote or mapped drive, a share, a verbatim or UNC form, a stream) is refused for every source and initiator; LaunchingExternalUriScheme is always cancelled and posted as Event::ExternalUri, opened only through guard_open (http, https, mailto, ftp; anything else shows "Tandem does not open <scheme>: links."); tool, popover, Quick Look and rasterizer views carry an allowed scheme list - cost if wrong: a page link to a registered handler (ms-msdt:, search-ms:) does nothing visible instead of Windows' own "open app?" prompt.
Ruling: B5 (page caps). Everything a page can post is capped before it is queued: a message at most 64 KiB and 50 per view per drain, a title 1024 characters with control and bidi characters removed, a URL 8192 bytes, a favicon 256 KiB and 256 by 256, new windows only for a user gesture at most 4 a second and 8 pending, a per-view pending counter of 256 events or 1 MiB with Created, Failed, Navigated, Focus and ScriptDone never dropped; invoke_request is a closed set (16 KiB, exactly the keys invocation and callback, callback matches a name pattern) - cost if wrong: under a flood a page's latest title or message is lost (see the Task 1 decision on newest versus oldest).
Ruling: B6 (focus). FocusActions is the complete table, one field per statement group of the old WindowEvent::Focused arm, the arm calls only the table, and a source test (focus_arm_statements_are_classified) fails on any call not classified, so a statement a later plan adds must be classified; IntoOwnChild runs only mouse and key cleanup, never the window-level loss - cost if wrong: a new statement in the arm fails a test until it is classified.
Ruling: B7 (UI Automation). access_target answers None while a web view holds the keyboard or the focused pane is a browser pane, so a screen reader follows the page; a browser pane's snapshot is a Group named "Browser: <title>" with no text range and no caret - cost if wrong: a screen reader enters the page only through the page's own provider (tab or focus); GetProviderForHwnd is not wired.
Ruling: B8 (logging). A page's console text, window.onerror text and COM error text are never logged; a line records an origin (dlog::origin: scheme and host only) and a byte count; rlog! only for low-frequency facts (runtime found or missing, store ready or failed, view failed, browser pane started) - cost if wrong: debugging a tool page needs DevTools (the web inspector), not the debug log.
Ruling: B9 (Instant Replay key and bound). The profile key is a new schema row Instant Replay (General, mode browser, default false, iTerm2's label and help) and the memory bound is the global IRMemory in MB (0 = off) - cost if wrong: none (the keys iTerm2's plan named did not exist in Tandem).

Pre-flight rulings P1 to P24

Ruling: P1. scrub_env removes WEBVIEW2_BROWSER_EXECUTABLE_FOLDER, WEBVIEW2_USER_DATA_FOLDER, WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS, WEBVIEW2_RELEASE_CHANNEL_PREFERENCE, WEBVIEW2_PIPE_FOR_SCRIPT_DEBUGGER and WEBVIEW2_WAIT_FOR_SCRIPT_DEBUGGER from Tandem's own environment before the first environment or version query - cost if wrong: a developer's own override variable is ignored in Tandem.
Ruling: P2. The fixed runtime hint follows B2 (judged, signed, bounded at the write, banner on refusal, no Evergreen fallback) - cost if wrong: a fixed runtime in a user-writable folder is refused.
Ruling: P3. User data folders are %LOCALAPPDATA%\Tandem\WebView2\{Default,Browser} from SHGetKnownFolderPath (never the LOCALAPPDATA variable), judged by LocalPath::judge, made with an owner-only protected DACL set once (an existing folder that passes is left alone; a failing one is repaired on a worker, never on the UI thread), with ExclusiveUserDataFolderAccess; all Tandem browser profiles share the one Browser store (iTerm2's fixed user) - cost if wrong: a redirected LocalAppData disables the browser with one banner instead of connecting to a share, and two browser profiles share cookies.
Ruling: P4. Dev Null uses a fresh folder per run (Tmp\DevNull-<pid>-<hex8>) plus InPrivate; webhost_win::cleanup_files runs from the one teardown_process and a launch sweep removes entries whose pid is dead - cost if wrong: a Dev Null folder lingers until the next launch if msedgewebview2.exe still holds it.
Ruling: P5. Every view is created with host objects off (a source test bans AddHostObjectToScript), web messages on only for popover HTML, tool views (logger) and iterm2-about: pages, autofill and password autosave off, every PermissionRequested denied (until 13x6), no ServerCertificateErrorDetected, ClientCertificateRequested, BasicAuthenticationRequested or DownloadStarting handler in 13x (WebView2's defaults stand, so a certificate error is blocked and Edge applies the Mark of the Web), and ProcessFailed recreates a browser view once - cost if wrong: pages that ask for the camera or location see a denial until 13x6; a download uses Edge's own UI.
Ruling: P6. The popover bridge honors a message only from the document the popover loaded itself, after which any navigation ends it, 20 calls a second; as built it is the exact served URL (see "Ledger rulings") - cost if wrong: an HTML popover that navigates itself loses its bridge.
Ruling: P7. Quick Look and the SVG rasterizer are InPrivate on the default store; tool views keep the persistent Default store; later every HTML popover is InPrivate too (Task 5 fix) - cost if wrong: Quick Look never shows a logged-in page, and tools share cookies with each other.
Ruling: P8. iterm2-about: pages come from an include_str! table keyed by exact page name (welcome, history, bookmarks, iterm-browser-common.css), never read from disk or joined to a path; a request is answered only for a main-frame document navigation or from a local top URL; the scheme is registered not secure with no authority and no allowed origins; any other name is a 404 under the same policy headers - cost if wrong: a page that framed History for fun stops working (a frame from a web page gets a 200 that frame-ancestors none refuses, checklist row 60).
Ruling: P9. Page-to-host handlers of the three local pages are a closed set per page; each argument is typed and bounded; a message's handler must be the source page's own, so clearAllHistory acts only from the history page - cost if wrong: none seen.
Ruling: P10. The browser database is %LOCALAPPDATA%\Tandem\browserdb-<user>.sqlite (machine-local, never roaming), judged, made owner-only, opened through the one localfs::open_database, trusted_schema off, a foreign or corrupt file set aside as .bad and replaced; bounds at the one write point: a URL over 2048 bytes or with a control character not stored, user:password@ stripped, titles through display_text and cut to 512, 100 000 history and visit rows (oldest first), 20 000 bookmarks (a full table refuses the new one), every limit at most 500 - cost if wrong: history does not roam to another machine, and a person at 20 000 bookmarks cannot add one.
Ruling: P11. Open Quickly entries show browser::display_title (120 characters) and display_url (punycode host); activation re-runs normalize_url and loads only http, https or iterm2-about: - cost if wrong: an IDN look-alike or a bidi-reversed title could spoof a site in the list.
Ruling: P12. open_link takes only a URL from Run::Open (http, https) or a judged local path; compatible_file refuses a colon (alternate stream) and never lists a runnable extension (exe, lnk, ps1, bat, cmd, hta, js, vbs); mailto and ftp stay with the system - cost if wrong: a crafted file: link would open an unjudged path in the browser (as built, no file: route exists at all: see Task 9).
Ruling: P13. SearchCommand and SearchSuggestURL are used only when http or https and holding %@, AdblockListURL only when https; a refused value logs one line and shows a banner once per run - cost if wrong: an imported file: or javascript: search template would be navigated.
Ruling: P14. The ad block list is https only, at most 8 MiB (enforced while streaming, plus a 300 s total deadline) and 100 000 rules, parsed, compiled and saved on a worker (temp file made with create_owner_only, then rename); matching has a 2 ms per-request budget (a rule that is over budget lets the request through and is counted), at most 64 requests judged per tick and a 4096-byte URL cut - cost if wrong: a hostile or huge list can only let ads through, never freeze Tandem.
Ruling: P15. BrowserProxy values come from Globals only; the environment's arguments are exactly proxy_args(..) or empty (a test pins it, and Env::create refuses any other); host bounded to 253 characters of letters, digits, dots, colons and brackets, port 1 to 65535, at the write point; a toolbar indicator and one notice show while the proxy is on - cost if wrong: an imported settings file could route all browsing through a stranger's proxy (it now shows the indicator); an authenticated proxy is not possible.
Ruling: P16. Browser Instant Replay is bounded: each ring at IRMemory MB (0 = off), 256 MiB over all panes (oldest first), a frame over 8 MiB or empty dropped, hidden and Dev Null panes never captured, Reveal writes the AVI to %LOCALAPPDATA%\Tandem\Replay under a random name through create_owner_only (swept at the next launch and at exit), the RIFF writer refuses over 1 GiB - cost if wrong: page screenshots of banking pages linger in a guessable temp file and a long session holds a gigabyte.
Ruling: P17. The tool and popover bridges are decided by what the host reads: tool views accept only the logger shape, Quick Look and the rasterizer accept nothing but their own ok or fail string, browser views accept only iterm2-about: handler messages - cost if wrong: none (13x2's secret scheme replaces it, one path).
Ruling: P18. No text from a program, a page or a model reaches navigate_to_string; as built (after the class ruling) navigate_to_string has no model-content caller at all, popover and icon content is served as a response with a header policy - cost if wrong: a terminal escape could render HTML in a view that has a bridge.
Ruling: P19. navigate_tandem's remembered URI is consumed by the first matching NavigationStarting and cleared at that navigation's end or after 30 s - cost if wrong: a later page navigating to the same URL would skip the guard.
Ruling: P20. A new-window request opens a tab only for a user gesture with scheme http, https or iterm2-about:, at most 4 a second and 8 pending - cost if wrong: a page opens hundreds of tabs.
Ruling: P21. The localfs source guard is extended in the same commit that adds a file (the database opens through localfs::open_database, so no OWN entry was needed) - cost if wrong: the guard test fails on the first build.
Ruling: P22. resources/browser/LICENSE-iTerm2 is a cp of resources/LICENSE-iTerm2 and a test asserts they are equal - cost if wrong: none.
Ruling: P23. The SVG rasterizer is InPrivate, blocks every request except data, caps an SVG at 256 KiB and the stored PNG at 256 KiB and closes after 5 s; as built the wrapper policy uses a per-page nonce (script-src 'nonce-...'), not P23's 'unsafe-inline', and arrives as a header - cost if wrong: none.
Ruling: P24. View bounds are cached per view and SetBounds is called only when the physical rect, scale or visibility changed; place_browser_views runs before the timed phases of build_frame (seam S12, later moved to the top of render) - cost if wrong: a COM call per view per frame.

Ledger rulings (progress.md)

Ruling: B1-B9 and P1-P24 accepted as written by the controller, except as changed below.
Ruling: static WebView2 loader. tandem.exe uses webview2-com's static loader (WebView2LoaderStatic.lib); there is no WebView2Loader.dll to ship, plant or miss, and the build copy, fetch script, load_bundled path for it and the pinned hashes are removed (load_bundled stays for ConPTY); dumpbin /dependents lists 34 system DLLs and no WebView2Loader.dll - cost if wrong: none (smaller attack surface); a future crate update that goes back to raw-dylib is caught by the inverted test dll::tests::the_webview2_loader_is_static.
Ruling: runtime selection. The runtime is the system Evergreen runtime unless BrowserPluginPathHint names a folder owned by Administrators, TrustedInstaller or the person (owner check plus no write for other users) holding a Microsoft-signed WebView2 runtime; otherwise it is refused with a banner. TrustedInstaller is accepted by the shared dynamic_profiles_trust::judge, so a TrustedInstaller-owned Dynamic Profiles folder is trusted too (only the OS can write it) - cost if wrong: a portable runtime in an unusual folder needs its permissions fixed.
Ruling: page console text is never logged (B8): a log line records origin and length only - cost if wrong: page debugging needs the web inspector.
Ruling: the 13u keyboard hook treats a web view holding the keyboard as not Tandem's terminal: it passes Win chords on (global hotkeys still run first), so Win+V pastes into the page, not the shell - cost if wrong: Win-chord menu shortcuts do not work while typing in a web page (the browser handles the Win chords Tandem has a command for from the page's key event).
Ruling (class): one window-remake hook for every hosted web view kind (HOSTED_VIEWS: file, remade, closing); a source test fails when a src/app file makes views and is not listed - cost if wrong: a new view kind that forgets the hook dies with the old window on a transparency remake.
Ruling: tool URLs are http or https only; file: tools are refused - cost if wrong: a tool that serves a local file needs a local web server.
Ruling: the popover policy keeps script-src 'unsafe-inline' (iTerm2 parity: the bridge reaches only built-ins and the RPCs the page's own API script has); then the content is served on Tandem's own random origin with the policy as a response header, InPrivate, no network, no frames, closed bridge at 20 calls a second - cost if wrong: HTML a script author injects into a popover can call those functions (and run inline script in a sealed origin).
Ruling (class): popover and icon content is served through WebResourceRequested on https://<hex>.tandem-local.invalid/<hex>/doc with the policy as a header; the HTML is never parsed or rewritten; every other request of the view is a 403; data: and blob: pass (no network); the bridge trusts the exact URL - cost if wrong: one request filter per view.
Ruling: popovers are InPrivate (storage a popover script writes goes with the popover; each document has its own origin) - cost if wrong: an InPrivate view shares one in-memory profile with other InPrivate views of the environment.
Ruling: the SVG allowlist. A chat icon candidate is refused whole unless every element and attribute is on the allowlist (ALLOWED_ELEMENTS, ALLOWED_ATTRIBUTES, xmlns by name), with caps (256 KiB, 2000 elements, depth 32, 32 uses) and no entity or doctype - cost if wrong: an icon using an attribute nobody listed clears the icon (the default shows).
Ruling: nonce CSP on local pages. Every iterm2-about: response carries script-src 'nonce-<uuid>' (no unsafe-inline, no unsafe-eval), a new nonce per response, inline handlers replaced by listeners - cost if wrong: those lines differ from iTerm2's files.
Ruling: suggestion gating. Text that normalize_url accepts and that has a scheme, a dot, a colon, a slash, a query, an at sign, a fragment or begins with localhost is never sent to the suggestion service; a bare single word is a search and is sent, as iTerm2 does - cost if wrong: no search suggestions for URL-like text; "intranet" is searched, and Enter navigates to it.
Ruling: host-end-visible URL display. The address field shows the host end always (fit_address cuts the path, then shortens userinfo to 4 characters plus an ellipsis, then cuts the host from its left); every IDN host shows as punycode - cost if wrong: a legitimate IDN looks technical.
Ruling: only Tandem's own pages are marked. The lock mark is Local only for iterm2-about:, about:blank and an empty address; blob: and filesystem: take their inner origin; data:, javascript:, other about: and every other scheme are not secure - cost if wrong: none.
Ruling: the per-window focus rule. The browser's focus hand-over (focus into or out of a browser pane, DECSET 1004 reports) runs only for the window in front, per window (FocusSeen<WindowId>); a background window's redraw never takes the keyboard, so a sudo password typed in another window stays there - cost if wrong: a browser pane in a background window learns of focus at the next time it is in front.
Ruling: ad-block caps and budgets. 8 MiB and 100 000 rules, 256 always-judged rules, 4096-byte URL cut, 2 ms per request, 64 requests per tick, 32 KiB first-use program limit, hiding selectors sanitized, a 300 s download deadline - cost if wrong: a list that needs more is partly ignored; an over-budget request is allowed.
Ruling: no file: route. Clicked local HTML or PDF paths get no "Open in Tandem" offer (the ask exists, unraised) and no new route for file:, UNC or custom schemes was added; they open in the default app - cost if wrong: the parity row stays partial; a person who wants a local HTML file in the browser types its file: URL (judged).
Ruling: the P10 gate (every_entry_point_is_gated) covers every opening call: SINKS include execute_with, open_link, open_link_system, open_url_in_browser, open_link_answered and upsell_answered, and a planted ungated call fails the scan - cost if wrong: a new opening call must be gated or listed with a reason.
