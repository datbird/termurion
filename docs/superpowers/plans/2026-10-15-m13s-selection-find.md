**Goal:** a person selecting, copying and searching in Tandem gets exactly iTerm2's behavior: a double click selects what iTerm2 calls a word (with their own word characters or a regular expression), Win-drag adds more selections that copy together, Select Matches selects every match, a keystroke clears the selection, one find query is shared by every find bar, Find URLs and URL clicks find only what iTerm2 finds (so "example.com" alone is not a URL), dragging past the pane's edge scrolls, dragging a selection drops its text into another app, a click on a command restricts Find, Filter and Select All to it, and Filter and Zoom show their lines in color.

**Architecture:** pure models first, each a plain `pub mod` tested on the Windows test machine. `wordsel.rs` is iTerm2's word extractor over a `find::Logical` line (character classes, the regex atoms, the same-class run, the segmentation refinement through a `Segmenter` trait with a `#[cfg(windows)]` ICU implementation from Windows' `icu.dll`). `seltext.rs` is the selection text model: sub-selections (`Sub`), iTerm2's range enumeration (overlaps cancel, connectors, end-of-line flags), and the text extraction with trim and trailing-newline options, over a `Cells` trait implemented for `Screen`. `dragtext_win.rs` (`#[cfg(windows)]`) is the OLE drag source (IDataObject and IDropSource) for dragging text out. `cmdsel.rs` is command selection's region rule and shade geometry. The app side: `src/app/selection_ui.rs` (word and line selection, multiple selections, copy through `seltext`, autoscroll, drag out, command selection), extended `find_ui.rs` (delay, direction, the shared query, auto search, restriction), `labels_ui.rs` (Find URLs), `synthetic.rs` (colored Filter and Zoom, the chunked filter). Per-pane state (`Pane.extra_selections`, `Pane.live_mode`, `Pane.sel_window`, `Pane.selected_command`) lives on the `Pane`; the shared find query (`App.find_pasteboard`), the autoscroll clock (`App.sel_scroll`) and the drag-out candidate (`App.drag_out`) are app-wide; no new field is per window, so none goes in `swap_live`.

**Tech Stack:** as milestones 0 to 12 (wgpu 30, winit 0.30, egui 0.36, glyphon 0.12). No new crates: `regex` and `fancy-regex` (already used by `smartsel.rs`), `windows-sys` `Win32_Globalization` (ICU word breaks, already enabled), and the `windows` crate (0.62, already a dependency) gaining features `Win32_System_Ole`, `Win32_System_Com`, `Win32_System_Com_StructuredStorage`, `Win32_System_Memory`, `Win32_System_SystemServices` for the drag source's COM objects. ### Decisions (each goes in `m13s-rulings.txt`)

- NSAttributedString's double-click word boundary maps to ICU's word break iterator from Windows' `icu.dll` (through `windows-sys` `Win32_Globalization`); without it the class run stands. Cost: boundaries in some scripts differ slightly from macOS.
- A click past a line's last character selects only that empty cell's run to the line end as whitespace (alacritty keeps no null cells). Cost: iTerm2's Null class differs on lines with written trailing spaces.
- With TrimWhitespaceOnCopy off, a line keeps spaces up to the selection's end on that row (alacritty cannot tell written spaces from empty cells). Cost: extra padding iTerm2 would not copy.
- Extra selections live on the `Pane` beside alacritty's live selection and die with it (`sync_selection`). Cost: output that clears alacritty's selection also clears the extras, as it clears iTerm2's selection when lines scroll away.
- A Win-press on a Semantic History target still opens it at the press (Tandem's Win-click precedent); a Win-press on plain text starts an appending selection. Cost: a Win-drag that starts on a URL opens it instead of appending.
- Dropped names (R10, decided by the 13s-u rulings exactly as written here): with the key off a name is quoted when it holds whitespace or one of `&()[]{}^=;!'+,\`~%` (cmd and PowerShell special characters), never backslash-escaped (backslash is the Windows path separator); with it on every name is wrapped in double quotes without escaping (a Windows path cannot hold `"`). Cost: a WSL shell gets Windows-quoted paths.
- The shared find query lives in Tandem only (`App.find_pasteboard`); Windows has no system find pasteboard. Cost: no sharing with other apps.
- The OLE drag offers CF_UNICODETEXT only (iTerm2 offers the string type). Cost: targets wanting RTF get plain text.
- The command selection info shows as a popover at the click with the link; the double-click interval is `clippings_ui::double_click_ms` (`src/app/clippings_ui.rs:34`, `GetDoubleClickTime`; reuse it). Cost: none.
- A chunked filter runs 20 000 logical lines per event-loop pass. Cost: a filter of a huge buffer takes several frames.
- `SwapFindNextPrevious` help text replaces "macOS" with "Windows" (the Texts rule). Cost: none.
- Parity rows are found by title.

### Pitfalls for the implementer

- Every `term_mut().selection =` in `src/app/` and `src/pane.rs` must become `set_selection`/`clear_selection`; `grep -rn "selection = " src` after Task 3 must show only tests and `pane.rs`'s helpers.
- `copy_selection` is also called by key actions and copy mode: route all through `selected_text` so extras copy everywhere.
- `wordsel` offsets are byte offsets into `Logical::text`; convert with `Logical::pos_before`, never by character counts.
- `fancy_regex` anchored matching: use `Regex::find_from_pos` and accept a match only when it starts at the position (there is no `.anchored` flag).
- `ubrk_*` in `icu.dll` may be absent on older Windows 10: load it with `LoadLibraryW` and `GetProcAddress` behind a `OnceLock`, never link it statically.
- `DoDragDrop` runs a modal loop on the UI thread and swallows the mouse release: clear `Drag::Select` and `drag_out` before calling it; OLE needs `OleInitialize` on that thread once.
- The shade and outline go in `Frame.overlay` (no text); the INFO popover has text and goes in `Frame.popups` with `scene::cut_out`.
- Command selection must not fire for a first-mouse click (13j Task 6's `first_mouse_down`, `PTYTextView.m:7870-7970`) or a click that a fold arrow, a note, the key cursor, Alt-click or a Smart Selection consumed; put it last in `mouse_release`'s empty-selection branch.
- `Results::label`'s caller must pass the swap flag; the find bar and the API's count read it.
- The shared query must not retrigger a search in every pane: only the key window's focused bar loads it.
- Nothing here is per window; `swap_live` is untouched.
