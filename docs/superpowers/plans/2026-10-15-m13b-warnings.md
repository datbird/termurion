### Pitfalls for the implementer

- `Ask`'s shape changes for every 11d and 13a constructor; move each into a `Spec` (the compiler lists them); keep their `Then` handling unchanged. `Then::remembers` becomes `Then::never_remember`; OpenNewScript's "Show in Explorer" must stay unremembered.
- A close with no button (`Answer::Closed`) never remembers, never records and never calls `scripts_answered`.
- Never remember an answer when the button is the spec's `cancel` or in `never_remember`, even with the box checked.
- The catalog records only automatic answers (`Preempt::Answer`), never shown dialogs.
- The Suppressed Alerts item is in every window's menu bar (`MenuBar` is per window); retitle the parked ones too.
- `NoSyncClearAllBroadcast` false means "not silenced", never "current only".
- A host change offer must not queue twice for the same identifier while one is waiting.
- Do not probe a UNC working directory when checking an arrangement's folder.
- The frustration detector is per pane (on `Pane`); the Suppressed Alerts window and `show_remembered` are app-wide; none goes in `swap_live`.
