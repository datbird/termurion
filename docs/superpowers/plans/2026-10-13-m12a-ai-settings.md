**Goal:** a person can open Settings > General > AI and set it up exactly as in iTerm2: turn on "Enable generative AI features", store an API key per vendor that never shows in the password manager, pick the default model (a vendor's recommended catalog model or a manual model), add and edit manual models with presets and custom headers, edit and reset every prompt, and set the eight default chat permissions; every AI entry point asks the gate first and says why it refuses, and asks once per host before any request would leave the machine.

**Architecture:** pure models first, each a plain `pub mod` tested on the Windows test machine. `ai_settings.rs` holds the stored key names, iTerm2's four enums with raw values and display names, and `allowed`. `ai_catalog.rs` decodes the bundled `resources/ai/ai-models.json` (a byte copy of iTerm2's) fail-safe and answers the default, recommended and economy models. `ai_policy.rs` is URL host parsing, the private-address test, the key policy, the auth headers, custom header rules and withheld-key advice. `ai_models.rs` is the manual model dictionary, manual vendor classification, the default model's endpoint, the popup's writes, the sheet's actions, the editor's form and Save rules, presets, and the legacy header migration. `ai_keys.rs` is the per-vendor key cache over a `KeyStore` trait, with a `#[cfg(windows)]` Credential Manager store built on new generic-target functions in `pwm_credman.rs`. `ai_gate.rs` is the gate's decision, its alerts and the consent list. `ai_prompts.rs` is the prompt defaults (`resources/ai/prompts/*.txt`), the required-variable rule and the evaluator on `interp`. Windows: `settings_ai.rs` (egui, drawn inside the settings window; not `#[cfg(windows)]`, so its pure helpers test anywhere) and `secret_field.rs` (the password field moved out of `pwm_ui.rs`). The app side is `src/app/ai_app.rs` (gate alerts, consent, reveal). Every new App field is app-wide; none goes in `swap_live`.

The catalog decodes as iTerm2's: the bundled file byte for byte, per-vendor recommended, economy keeping the configured transport, fail-safe for unknown enum strings but a whole-file refusal for a missing required field. Test: Task 2 `bundled_catalog_is_iterm2s`, `catalog_decodes_like_iterm2`, `economy_keeps_the_transport`, `fail_safe_decoding_follows_iterm2`.

### Pitfalls for the implementer

- A key is a `Secret`: never `format!` it, never put it in a test assertion message, never let `egui::TextEdit` hold it (use `secret_field`, which edits the `Secret` in place); the fake store logs targets and users, never key text.
- Do not call Credential Manager in any test, nor run anything in the user's interactive session (m10b ruling); `generic_targets_are_guarded` only exercises refusals that return before any Win32 call.
- `Globals::set` removes values equal to the default: assert with `g.int`, `g.bool`, `g.string`, not `g.values.get`, except where a test checks that nothing was written.
- The prompt defaults live in files, not in the schema; `default_of` must answer them before the schema lookup, or Reset and `Globals::string` return "".
- `resources/ai/ai-models.json` is copied with `cp`; an editor that rewrites line endings breaks the digest. Same for the prompt files (no trailing newline, LF only inside) **except** `code-review-system.txt`: the source file ends with "\n" and its 2361-byte digest includes it, since `iTermBundledCodeReviewSystemPrompt` reads the file unchanged; keep that trailing newline, do not strip it to match the other ten (review fix).
- `select_manual` must not call `model_did_change` afterwards (iTerm2 sets `_lastModel` to stop exactly that), or a manual model's URL is overwritten by a same-named catalog model's.
- The popup's unmatched default must not write; a change is only a person's pick.
- The consent host is the normalized host (lowercase, no trailing dot); compare normalized on both sides.
- New App fields are app-wide `Option`s; none goes in `WinSlot` or `swap_live`.
- `schema_page_with`'s closure receives `g` as its second parameter; never capture `globals` in it (the scroll area already holds it mutably).
