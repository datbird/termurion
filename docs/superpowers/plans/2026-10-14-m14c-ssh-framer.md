### Decisions (each goes in `m14c-rulings.txt`)

- framer.py and it2ssh ship byte for byte (`resources/ssh/`, pinned by SHA-256 for framer.py); `VERBOSE=1` is never inserted (Tandem has no debug logging switch). Cost: none.
- alternateSSHIntegrationScript is not added (ruling 8). Cost: no local framer override for development.
- The `save` pairs go in the fixed order dcsID, sshargs, boolArgs, clientUniqueID (iTerm2's dictionary order is arbitrary). Cost: none; framer.py reads a dictionary.
- Wire quirks kept: `dereigster` for deregistration, the pre-framer `quit` with the line prefix on Disconnect and on the framed shell's exit, a job's double completion on stderr. Cost: as iTerm2.
- The time-offset script returns a third line, `time.localtime().tm_gmtoff`, and the Clock uses it for "Use server time zone" (Windows has no table from the zone abbreviation iTerm2 gets back to a UTC offset); the first two lines stay iTerm2's, so `get_time_offset` answers iTerm2's offset and tz. Cost: one Tandem-only value on the wire inside a `runpy` script.
- The Clock's globe is Segoe Fluent Icons U+E774 (Globe) after a space, not U+1F310 (no emoji; the bar already draws Segoe Fluent glyphs). Cost: a different glyph.
- Local values with no conductor: homeDirectory is `%USERPROFILE%`, shell is the shell integration's shell else the profile command's program name, uname is "Windows_NT" (the `OS` variable's value). Cost: scripts expecting a POSIX uname locally see "Windows_NT".
- `get_time_offset` with no conductor answers the Windows zone name (`GetTimeZoneInformation`'s standard or daylight name) as `tz`. Cost: a long name where macOS gives an abbreviation.
- The remote job is `proctree::display_job` over the root and the foreground (`+`) rows under it; names keep a login shell's leading "-" (iTerm2's `nameOfProcess`). Cost: a background remote job never shows as the job.
- The close prompt reads the last autopoll list; it does not wait for a fresh `poll` (iTerm2's provider can poll on demand). Cost: a job started less than a second before closing may be missed.
- A framing pane's CPU graph shows the remote CPU (iTerm2's per-session publisher); a host without `mpstat` shows no remote values. Cost: as iTerm2.
- Coprocess input while a conductor exists follows iTerm2: depth-0 channel -1 output only; a level-1 session's coprocess gets nothing. Coprocess output goes to the conductor (14b Task 10, `PK:354-361`). Cost: as iTerm2.
- `%it2` frames are parsed and routed by depth into `it2_inbox`, capped at the newest 16, which nothing reads (the it2 proxy is n/a by ruling 3; Tandem never sends `it2listen`). Cost: none.
- The 30 s command timeout keeps running after framing for every command that does not stream (rulings 14b-1 and 14d-1; 14b's `Command::streams`); expiry fails the conductor as during setup. Cost: a connection that stalls more than 30 s with a command in flight (a laptop asleep) ends SSH integration for that session (controller ruling pending on this case).
- No recovery boundary token: Tandem swaps the hook synchronously, so a restored or recovered conductor resynchronizes at once, and the rest of the read that held `:end-recovery` is dropped (iTerm2's Syncing mode drops what its parser had already read). Cost: a few bytes of output lost at recovery, as iTerm2.
- The conductor is restored only when the pane re-attaches to its tandem-host session; a fresh restore drops the three keys (the ssh process is gone). Cost: none.
- Duplicate Tab behaves as Duplicate Session (Tandem's Duplicate Tab opens one pane from the focused one); the new pane's local folder is Tandem's usual one, since a remote directory is not a local folder, and each hop's remote directory comes from its jump. Cost: none known.
- The "Can\u{2019}t Disconnect" warning has no suppression checkbox (iTerm2 passes no identifier). Cost: none.
- The Disconnect title is refreshed from the focused pane each loop and applied only when changed; the last shown title is a `WinSlot` field. Cost: none.
- In pipes transport mode (ruling 1) a local resize never reaches the remote. Cost: full-screen programs keep the old size; documented in the checklist.
- Parity rows are found by title.

### Pitfalls for the implementer

- Never write to the pty from a conductor path except `Effect::Write`; anything else while framing corrupts framer.py's command stream (it base64-decodes every line).
- 14b routes `Pane::reply` through `write_session`; keep it that way, or DA and cursor reports go raw into the framer.
- Autopoll and notif data carry pids -1000 and -1001 and channel 1: route them before looking up a background job, and drop their child parsers after each use.
- Depth: a child hook's meta tokens carry the child's depth, its screen text the parent's; mixing them up sends a nested conductor's replies to the outer one.
- `%end <id>` must match exactly: `%end 7` must not end `%output 70`.
- The side-channel reducer keeps state across reads (an escape split between two `%output` blocks of the same pid).
- Do not reuse Tandem's local job watcher values for a framing pane: they name ssh.exe.
- The time-offset latency uses a monotonic clock (`Instant`), the local now in the script uses the wall clock.
- `quit()` must fire no stale handler: canceled contexts get `.canceled`, and the Uname and Home purposes ignore it.
- `session_value` is also used for saved arrangements (no contents): the conductor keys go only with contents, Pending Jumps only without.
- The recovered hook's children follow the tree; a key 0 node is never hooked itself.
- The Disconnect title is per window (the menu bar lives in `WinSlot`): its shown-title cache must be in `swap_live`, or another window's title leaks in.
- `every_command_has_a_status` allows owners 4 to 14 after 14a Task 10; do not move the selectors again.
- Every conductor that leaves a pane (EndSSH, abort, Disconnect, recovery, pane close) must leave the registry and, except under EndSSH, pop its hop (14b's `ssh_unhook_conductor`); a stale registry entry keeps Download Files enabled for a host that is gone.
- `framer.py`'s SHA-256 pin and it2ssh's 193-line check depend on 14b Task 3's `.gitattributes` line `resources/ssh/** -text`.
