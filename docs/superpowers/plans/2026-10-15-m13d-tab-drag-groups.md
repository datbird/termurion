### Decisions (each goes in `m13d-rulings.txt`)

- No floating drag image window while dragging a tab: a drop marker in the source bar and the tab moving in the bar instead. Cost if wrong: less feedback when dragging outside the window.
- The side bar width is saved to `LeftTabBarWidth` on release, not on every move. Cost if wrong: none visible.
- The pinned tab close keeps Tandem's reason-list question with "Tab #N is pinned." added, instead of iTerm2's new per-subject bodies (a separate close-text sweep). Cost if wrong: wording differs from iTerm2's newest text.
- The icon map is parsed leniently (trailing commas dropped), treating the bundled set as working. Cost if wrong: icons show where iTerm2 at this commit may show only letters.
- The letter icon is a filled circle (`rounded_box`) with the letter drawn in the bar background color, not a knocked-out alpha. Cost if wrong: identical on an opaque bar; differs only over a transparent bar (13g).
- Tandem's `stop_at` also stops at "tandem-host" (the host that owns shells, the equivalent of "iTermServer"). Cost if wrong: an icon from Tandem's own host process.
- `LeftTabBarWidth` shows as a number field in Appearance > Tabs (iTerm2 has no control; Tandem's schema has no hidden rows). Cost if wrong: one extra row.
- The window title bar does not show the tab graphic (Windows' caption icon stays the app icon). Cost if wrong: small.

### Pitfalls for the implementer

- Every `Tab { .. }` literal must become `Tab::new(..)` (including `src/app/undo_ui.rs:144`, `:202`, `:203`); `grep -rn 'Tab {' src/app` after Task 1 must show only the struct, the `Undone::Tab` variant (`undo_ui.rs:13`) and `api_tab`.
- `tab_height` still returns the horizontal bar height; code that asked "is there a bar" must switch to `tab_bar_rect`, or a bottom or side bar double-counts room. The tmux size report reads the pane rects, so it follows `window_room` automatically; verify with a tmux tab and a side bar.
- `self.active = i` appears in many places; Task 4 routes tab switches through `select_tab` so the flash and group expansion happen once. Grep for `self.active =` and convert the user-visible switches (tab click, next/previous, Win+number, MRU cycle, API activate); restoring or merging windows may assign directly.
- A drag between windows swaps window state (`enter`): take the tab before entering the target, and never hold a `&Tab` across `enter`.
- Hidden (collapsed) tabs keep a zero-size rect in `bar_tab_rects` (13c's `build` gives them no cell, Task 9) so indices line up with `tabs`.
- Muda menu labels need `&` doubled (`label.replace('&', "&&")`), as `show_context_menu_with` does.
