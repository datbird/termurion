### Decisions (each goes in `m11e-rulings.txt`)

- One multi-call console program `tandem-utils.exe` (`src/bin/tandem-utils.rs`), choosing the utility by its own file stem or, run as itself, by its first argument; Tandem makes `utilities\<name>.exe` hard links to it (copies when a link fails) beside tandem.exe at every start and writes `utilities\it2api.py`. Cost: Tandem writes into its own folder at startup; in a read-only install folder the utilities are not on PATH and a banner says so.
- PATH: the `utilities` folder is appended to the end of each new session's PATH when `addUtilitiesToPATH` is on (default), iTerm2's order and rule, built from Tandem's own PATH. Cost: another `imgcat` earlier on PATH wins; a tandem-host started with a different PATH gives new sessions Tandem's PATH.
- The version: `CSI 1337 n` answers `ITERM2 3.7.0`, the iTerm2 line Tandem follows (the reference clone's 3.7), through a new `reports::ITERM2_VERSION`; XTVERSION keeps "Tandem <crate version>" and the crate version is not changed (version numbers are Robert's call). Cost: programs that gate features on iTerm2 3.7 turn on some Tandem does not have.
- Session variables are iTerm2's values: `TERM_PROGRAM=iTerm.app`, `TERM_PROGRAM_VERSION=3.7.0`, `COLORTERM=truecolor`, `TERM_FEATURES`, and under `shouldSetLCTerminal` `LC_TERMINAL=iTerm2`, `LC_TERMINAL_VERSION=3.7.0`, so programs that detect iTerm2 (inline images, notifications) work in Tandem. Cost: those programs treat Tandem as iTerm2, macOS-only behavior included.
- base64 is written as macOS's `base64` writes it (one line; it2copy keeps the trailing newline inside its OSC, as `base64 | cat` does). Cost: bytes differ from a GNU system's wrapped output (Tandem and iTerm2 ignore the whitespace).
- Replies are read from the console in raw or cbreak mode through `ReadConsoleInputW`, a focus-in record read as `ESC [ I` while a reply is awaited; every changed console mode is restored at exit, on Ctrl+C and on panic. Cost: a real focus change during the wait reads as the start of a reply (the script is equally exposed to a focus report).
- `/dev/tty` is `CONIN$`/`CONOUT$`; `$(basename $0)` is the utility's name without ".exe"; names in `name=` are UTF-8. Cost: none.
- imgls measures images with Tandem's own decoder (the `image` crate, method name "image") instead of sips, mdls, php, exiftool or Image::Size, fills the long listing from Win32 (modes as Perl's Windows `stat`, link counts, file index, allocation blocks, owner and group account names, SIDs with `-n`) and writes `File=` parameters in a fixed order. Cost: `--method sips` finds nothing; owner and group are Windows names.
- imgcat/it2cat `-u` run `curl.exe` and it2ul runs `tar.exe` (both in System32 since Windows 10 1803), as the scripts run curl and tar, so it2ul's extra arguments still go to tar; it2dl archives folders in-process with the `tar` and `flate2` crates. Cost: without curl.exe, `-u` fails with the script's missing-dependency error; it2dl's archive headers differ from bsdtar's.
- it2git runs the git that `git_state::find_git` finds instead of `/usr/bin/git`, and prints counts unpadded (GNU `wc`, not macOS's padded form). Cost: none.
- it2tip parses the vendored script's tips at run time and replaces only "iTerm2" (Mac key glyphs and menu names stay, per the milestone's text rule); an unset `TERM` counts as not screen (the script would crash on a tip with a url); the index file is `%XDG_DATA_HOME%\.it2totd` or `%USERPROFILE%\.it2totd`. Cost: some tips describe Mac keys or features Tandem lacks.
- it2api is iTerm2's Python script, shipped as `utilities\it2api.py` with its two "iTerm2" texts changed, run by the `it2api` entry with `py -3` or a `python.exe`/`python3.exe` on PATH outside WindowsApps; not a Rust port (it prints the package's own object renderings and argparse help, which a port would have to imitate). Cost: it needs Python 3 with `pip install iterm2`, and a cookie (`setCookie` and a new session) or "Allow all apps to connect", as any 11a script does.
- it2setkeylabel is ported (Tandem keeps the labels and shows them nowhere); the Swift `it2` CLI is not ported; it2ssh is milestone 14. Cost: no Windows `it2`.
- The upload picker: Windows cannot choose files and folders in one dialog, so a RequestUpload first shows the bar "Upload files or folders?" with Files and Folders; dismissing it cancels (^C). Cost: one more click than iTerm2.

### Pitfalls for the implementer

- Turn on `ENABLE_VIRTUAL_TERMINAL_PROCESSING` for a console stdout before writing, or every ESC shows as a glyph; do not touch code pages. Rust's stdout on a console needs valid UTF-8, which every string here is; binary never goes to a console (base64 only).
- `cargo test --lib` does not build `tandem-utils.exe`: the ConPTY tests re-invoke the test binary (`utility_child`), and the child must `std::process::exit` so libtest's summary does not decide the code.
- Never `std::env::set_var` in a test; the child's environment goes through `cmd.exe /c set NAME=value&&`, a utility's through `Harness.env`.
- Restore console modes on every path: Drop, the ctrl handler (return FALSE so the process still ends), and a panic hook in `real_main`; it2copy's handler must also write the pending ST.
- `Mode::Raw` turns processed input off (^C is a byte), `Mode::Cbreak` keeps it (^C ends the program): it2check is Raw, it2getvar, it2profile and it2ul are Cbreak.
- The host loop in `run_in_conpty` must drain output continuously and write back `Screen::feed`'s replies, or ConPTY stalls and it2check waits forever (the script has no timeout).
- `hard_link` fails when the target exists: remove it first; a running utility locks its file, so a failed refresh of one name is skipped, not fatal. Never delete files in `utilities\` that Tandem did not make.
- imgls's `sort` is byte order and its data base64 ends with "\n" (76-column lines); do not "fix" the black pixel's size 96.
- it2copy's `send_regular` prints the OSC head before reading stdin, and its tmux form is chosen by `tmux*` only; it2tip's link sequences differ from every other utility's (screen only, ST ending).
- A path starting `\\` or `//` is never probed (implementer rule): imgls and the file utilities treat it as missing.
- The Task 6 PATH value is computed per session from Tandem's own `PATH`; do not append to Tandem's own process environment.
