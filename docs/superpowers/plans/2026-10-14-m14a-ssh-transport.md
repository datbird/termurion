### Decisions (each goes in `m14a-rulings.txt`)

- The transport is the probe's (Task 1), tried in ruling 1's order; every option failing stops the milestone for Robert. Cost: as recorded.
- `CONDUCTOR_READY` is false in 14a: `SshWillBegin` and `SshSendConductor` are ignored by the app, `it2ssh` runs plain ssh with `NOT_READY`, and SSH profiles run `ssh <command>` with the `PROFILE_NOT_READY` banner; 14b Task 7 sets it true and deletes both notices (ruling 14a-1). Cost: 14a cannot show a live handshake.
- The chosen transport is used only for SSH-profile sessions with SSH Integration; other panes keep ConPTY flags 0; a pane started with another transport carries `TANDEM_SSH_TRANSPORT` (controller question 2). Cost: a typed `it2ssh` in an ordinary pane gets plain ssh when ConPTY failed the probe.
- The origin secret comes from `\\.\pipe\tandem-ssh-secrets-<SID>[-admin]`; iTerm2 sends "none" off macOS (controller question 3). Cost: a second Tandem of the same user cannot serve secrets (the name is taken) and its it2ssh sessions count as not local.
- The session host speaks protocol 4 (`LaunchWith`); an older host runs such a session inside Tandem (controller question 4). Cost: that session ends with Tandem.
- 11e's shared types grow: `Cmd::merge_stderr`, `Io::secret`, `Io::env_all` (controller question 5). Cost: every 11e `Cmd` literal changes.
- Env's base64 is Tandem's lenient decode (CR and LF dropped, padding optional), not apr's prefix decode of garbage. Cost: a corrupt payload is nil where iTerm2 might keep a prefix.
- Banners use the restore banner's grays and end with SGR reset (m8a precedent); iTerm2 restores the saved rendition. Cost: color state after a banner is default.
- The connecting queue is capped at 1 MiB (iTerm2 unbounded). Cost: a huge paste during connecting is cut.
- The secret set keeps the newest 256 (iTerm2 unbounded). Cost: a secret fetched 256 connections ago is refused.
- `%q` follows bash 5.2 in a UTF-8 locale (macOS's bash 3.2 differs for non-ASCII). Cost: non-ASCII arguments differ from a Mac's text; 14b parses Tandem's own.
- it2ssh's default ssh is `ssh` found on PATH (iTerm2 `/usr/bin/ssh`); on pipes stdin a second `-t` is appended. Cost: a PATH without OpenSSH needs Path to SSH.
- it2ssh does not create `~/.ssh/controlmasters` or `~/.ssh` (unused; OpenSSH for Windows makes `.ssh` when it writes `known_hosts`). Cost: none known.
- The letter test is a literal substring search (iTerm2 greps a basic regex). Cost: an option containing `.`, `*`, `[`, `^`, `$` or `\` may be classed differently.
- `command env` is the process environment in its own order as `NAME=value` lines. Cost: order differs from macOS (unused by iTerm2).
- An SSH profile's remote initial directory is the profile's custom Working Directory only when it starts with `/` or `~` (a Windows path cannot name a remote folder); iTerm2 sends the local `PWD`. Cost: profiles relying on the same path on both machines must use a POSIX path.
- SSH profiles run `utilities\it2ssh.exe` (11e's folder); when it is missing, plain ssh with a banner. Cost: none.
- Configure SSH: the variables are one text field split on whitespace and commas, stored as the array (iTerm2's tab-separated token field, which stores `[""]` when cleared; Tandem stores `[]`); "+" offers Files\u{2026} or Folder\u{2026}; the destination is asked in the sheet after the dialog; the Browse folder is the current path's or `C:\Windows\System32\OpenSSH` (no `NoSyncLastSSHDirectory`); a home prefix counts only at a folder boundary and ignoring case; a `filesToCopy` entry with fewer than two strings is skipped (iTerm2 would crash). Cost: a different look.
- Kept iTerm2 quirks: `--`, `-vvv`, `-tt` take the host; "it2sh" in the message; exit 255 without arguments and 0 after ssh; "2 ssh sessions ended.."; one pass of `\n\n`; the space before the intro; under `TERM=screen*` the wrapped intro ends in `\` before the closing quote, which breaks the remote command (by reading; UNVERIFIED by running). Cost: as iTerm2.
- EndSSH for a unique id no hop has ends connecting and drops the queued bytes (14a's single `connecting: Option<Vec<u8>>`); iTerm2 clears `_connectingSSH` but keeps `_queuedConnectingSSH` (`PS:20253-20259`), which only a later conductor would ever send, out of order with typing made meanwhile. Cost: bytes typed while such an EndSSH arrives are not sent later.
- it2ssh wraps its OSCs for tmux only under `TERM=screen*` (`IS:11-26`), not 11e's `screen*` or `tmux*` rule. Cost: none (parity).
- An SSH profile's Command reaches ssh.exe or `it2ssh.exe` through CreateProcess (MSVC word rules), while iTerm2 hands it to a shell with `-c`, so a Command like `host 'ls -l'` splits differently. Cost: POSIX quoting in a Command is not honored.
- A pipes-transport pane (only when Task 1 chose Pipes) has no console: Send Signal's Ctrl+C, the password-prompt detection through `console_mode` and the session host's `Signal` cannot reach it; each fails quietly, and Ctrl+C typed as a key still goes out as the byte 0x03 through the input path. Cost: no console-level signals for such panes.
- A pane started with `start_command_override` (the API's create command) never takes the SSH path. Cost: none.
- Parity rows are found by title.

### Pitfalls for the implementer

- The probe is the only test that talks to sshd, and only to its own on `127.0.0.1:22990`; never point it anywhere else, never leave sshd running (stop it on every exit path, a failed assertion included: do the cleanup in a guard's `Drop`).
- Copy fixtures and `Cargo.lock` back with `scp`, never through the sshfs mount.
- `conductor.sh` must stay byte-identical: no editor reformatting, no CRLF; the SHA-256 test and `.gitattributes` guard it.
- `write_no_broadcast` is the only path past the connecting queue; the conductor bootstrap, `\x03\n` and (from 14b) the conductor's own command bytes use it, and nothing else may.
- Never print, log or banner a secret, a token from `it2ssh=`, or a `Handshake` (its `Debug` holds the token): the report shows lengths only.
- `EndSSH` is trusted-only and `it2ssh=` is not; do not "fix" the asymmetry.
- `std::process::Command` quotes each argument for CreateProcess; pass it2ssh's arguments as a `Vec`, never joined into one string.
- The pipes `Pty` has no pseudoconsole: every `hpc` use (`resize`, `clear`, `Drop`) must check for 0.
- `host_proto` message 21 must never reach a host below version 4 (an unknown message breaks the stream).
- The Configure\u{2026} sheet edits the profile the Settings page shows (a session copy when divorced, implementer-rules).
