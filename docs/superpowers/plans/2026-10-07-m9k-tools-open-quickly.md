## Review Focus

1. A Capture Output trigger stores the whole line on the last command mark, merges a grown line into the last entry, stores nothing without a command mark, and a Clear hides only what was captured so far. Test: Task 2 `capture_follows_iterm2`.
2. Session Status order: un-snoozed first, then pattern priority (case-insensitive substring, unmatched = count, no text = count + 1), then older change first; the tab subtitle picks by the same user patterns. Test: Task 3 `status_rows_sort_like_iterm2`.
3. Jobs signals on Windows: INT and QUIT reach the console, HUP, ABRT, KILL and TERM terminate with 128 + the signal; the question counts the selection and says "and their children" only when a selected row has children. Test: Task 1 `jobs_rules_follow_iterm2`.
4. Notes edits text natively: typing, Enter, Tab, Backspace, Delete, arrows across soft-wrapped lines, Home and End, selection with Shift, Ctrl+A/C/X/V/Z/Y, and a click placing the caret; a note over 100 KiB saves on a 2 s trailing debounce. Tests: Task 4 `text_edit_follows_windows_edit_rules`, `notes_save_like_iterm2`.
5. Open Quickly scoring: smallest-span subsequence, quality 1.0 / 0.9 / 0.5 over runs, newest document undiscounted, per-feature caps, empty query 0.01 per non-empty feature, the current session never listed, top 100. Test: Task 5 `scores_follow_iterm2`.
6. Keys never leak to the shell: a focused Notes editor takes printable keys, Enter and Tab and its Ctrl chords; the Open Quickly window takes every key while it has focus and closes when it loses it. Tests: Task 4 `text_edit_follows_windows_edit_rules` (`takes`), Task 8 `palette_keys_follow_iterm2`.

### Corrections to the research (the source wins)

- The suppress key is `NoSyncSuppressCaptureOutputToolNotVisibleWarning` (capital N, `PS:381-382`; the advanced setting name capitalizes its first letter). - Captured Output's search field has no placeholder; the label has no space after the check mark.
- Session Status' tab subtitle uses the user's priority patterns, not the fixed list, and shows the display form (Working, Waiting, Idle); Tandem's `tab_look` uses `PRIORITIES` and the raw text today. The status-change alert uses the display form too.

### Decisions (each goes in `m9k-rulings.txt`)

- Dynamic web tools are deferred whole to milestone 11 (no registry read): only `RegisterTool` writes `NoSyncDynamicTools`, and Tandem has no API or WebView2 host yet. Cost: none until 11.
- Notes uses a native multi-line editor in the panel (`text_edit.rs`, one pure task plus drawing), not the egui NoteWindow, for parity (in-panel, toolbelt font, keeps the toolbelt keyboard model). Cost: no IME composition, no spell check, no rich text; the global file is plain UTF-8 `notes.txt`, not RTFD.
- Notes takes Ctrl+A/C/X/V/Z/Y and Ctrl+Shift+Z (Windows edit control keys) plus Enter and Tab while it has the keyboard; other chords pass.
- Jobs signals on Windows: INT is `CTRL_C_EVENT` and QUIT `CTRL_BREAK_EVENT`, sent to the process's whole console (as Ctrl+C typed in the pane is); HUP, ABRT, KILL, TERM are `TerminateProcess` with exit codes 129, 134, 137, 143; the signal box lists only the six. Cost: INT reaches every process on that console, not only the selected one; a GUI child ignores INT and QUIT.
- The job tree comes from the job watcher's thread (a tree kept for panes whose Jobs tool shows), never a UI-thread snapshot.
- Inspect shows the pid and the command line only; iTerm2's richer job info view is deferred.
- Session Status: Tandem has no peers or workgroups, so no peer label or peer shortcut, and Merge workgroup statuses is stored but changes nothing; shortcut labels use Windows modifier words ("Ctrl+2", "Win+4"); patterns are a TOML array of tables in the globals.
- Popovers (Session Status settings, Inspect) are borderless egui host windows that close on focus loss.
- Codecierge: `EnableAI` is always off until milestone 12, so the tool shows the NeedsAi message; "Reveal Setting" answers with an info bar "AI features come in milestone 12."; `GenerativeAIAllowed` is an Advanced setting so the admin message can show.
- Open Quickly is an egui host window (the `GlobalFindWindow` model) plus a second borderless window for the preview; the preview image is `render_lines` of the visible screen, cached per pane.
- Open Quickly sources Tandem lacks: color presets (milestone 13), scripts (milestone 11), function invocation (milestone 11), browser bookmarks and URLs (no browser profiles); their tips stay. Windows show no "On other Space" (virtual desktops are not tracked).
- Session features: directories are the session's `shell.history` directories plus its current one; hosts likewise; the user is `shell.user`; tty is empty; git branch only when the pane's git poller already has one; focus ordinals are kept for this run only (iTerm2 persists them).
- Icons are Segoe Fluent glyphs: session `\u{E756}`, window `\u{E737}`, new tab `\u{E710}`, change profile `\u{E8AB}`, arrangement `\u{E7C4}`, tip `\u{E946}`, action `\u{E945}`, snippet `\u{E8BD}`, named mark `\u{E8A4}`, menu item `\u{E700}`; no generated session logo.
- The Open Quickly hotkey id is `u32::MAX` beside `APP_HOTKEY`; a press brings only the palette forward and a commit brings Tandem forward.
- Parity rows are found by title.
