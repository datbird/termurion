# P1 Unix Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On Linux and on the macOS VM, a window opens, runs zsh/bash, tabs and splits work, tmux `-CC` attaches, and restore after restart works, with Windows behavior unchanged.

**Architecture:** The P0 facades stay as they are; P1 replaces the Unix stand-ins behind them with real backends, written once in `src/platform/unix/` (and `platform/linux/`, `platform/macos/` only where the OS reads differ: the process table). The pty is our own small `openpty` + `std::process::Command` backend with the same `Pty` contract as ConPTY (reader thread, writer thread, pause, exit code); the session host speaks the unchanged `host_proto` over a Unix socket in a private runtime folder. Last, the cfg(unix) twins P0 left in root modules move under `platform/`.

**Tech Stack:** Rust 2024, libc 0.2 (Unix, already a dependency), std `os::unix::net`, arboard 3.6 (gains the `wayland-data-control` feature on Linux), alacritty_terminal 0.26 (vendored; its `tty` module is not used, see Task 1), tmux 3.x for the live check.

**Spec:** `docs/superpowers/specs/2026-10-31-macos-linux-port-design.md` (binding). Conventions follow `docs/superpowers/plans/2026-11-01-p0-compile-everywhere.md`. Test status by cause: `docs/port/unix-test-gaps.md`.

## Global Constraints

- "Windows behavior unchanged. Every step keeps the Windows build and its tests green." Each task ends with `scripts/xt test --lib` full PASS (the known flake `find::tests::find_over_a_large_buffer_is_quick` is the only allowed failure, rerun once).
- "No second copy of any logic. If Mac and Linux need the same thing, it lives once in `platform/unix`." Logic shared with Windows (the job watcher loop, `read_until`) lives once outside the backends.
- "No `#[cfg(windows)]` sprinkled through `app/`." A cfg lives only in `src/platform/`, `src/lib.rs`, `src/bin/`, `Cargo.toml`, `*_win.rs`, or a `scripts/cfg-audit.allow` entry; `scripts/cfg-audit` exits 0 after every task.
- Unix code never claims success for something it did not do: a missing facility returns `platform::Unsupported`, never a silent `Ok`. The one allowed no-op class is a call with no meaning on that OS, with a doc comment saying why.
- Nothing blocks the UI thread: clipboard reads, file-manager calls and openers run off it.
- Every new process spawn, URL/file open or fetch funnel gets a `SINKS` token, a `NOT_PANE_TEXT` entry and a planted case in `src/app/semantic_ui.rs`.
- `dlog!` arguments are `LogSafe`; any task that adds or moves a `dlog!` updates `dlog::CALL_SITES` (per-file counts).
- Builds: Linux checks and tests run here with `~/.cargo/bin/cargo`; macOS runs on `ssh funtimes` (arm64, rustc 1.99.1) through `scripts/check-unix`; Windows through `scripts/xt`. Every task checks both Unix hosts.
- Short human comments, no em dashes or emoji anywhere, commits with no host or user names and no attribution lines, work on `main`, do not push.

## Review Focus

1. Termurion started from inside another terminal or tmux inherits `TERM`, `TMUX`, `COLORTERM`, `ITERM_SESSION_ID`, `KITTY_WINDOW_ID` and the like. Expect the pane's shell to get the profile's `TERM` and none of the outer terminal's variables (else tmux refuses with "sessions should be nested" and programs draw for the wrong terminal). Pinned by `outer_terminal_variables_never_reach_the_shell` in Task 1.
2. A pty master or socket inherited by another child (a missing close-on-exec). Expect no pane's shell to hold another pane's pty, else closing a tab never ends its shell and EOF never comes. Pinned by `a_shell_inherits_no_other_pty` in Task 1.
3. A stale socket file left by a crashed host, a runtime folder with the wrong owner or mode, a symlink planted in `/tmp`, or a socket path past the 104-byte macOS limit. Expect the stale file replaced, a foreign folder refused with a message naming it, nothing followed, and a long path refused by name. Pinned by `a_stale_socket_is_replaced`, `a_shared_runtime_folder_is_refused`, `a_long_socket_path_is_refused` in Task 4.
4. Closing a pane whose shell ignores SIGHUP or left a background job on the tty. Expect the close to return at once (under 500 ms) and the child gone within 3 s, with no zombie left. Pinned by `drop_ends_a_shell_that_ignores_hangup` in Task 1.
5. A profile command line written for Windows (`pwsh.exe -NoLogo`, `"C:\Program Files\x.exe"`) or with an unclosed quote. Expect a pane error naming the command, never a panic and never a string handed to a shell. Pinned by `split_follows_posix_quoting` and `a_missing_program_reports_the_command` in Task 1.

A per-child waiter thread replaces the spec's `SIGCHLD`: a process-wide handler would reap the children `std::process::Command` waits on elsewhere (git, curl, coprocesses).

### Task 4: The session host over a Unix socket

Owns: all 19 of "Session host is Unsupported".

**Files:**
- Rewrite: `src/platform/unix/ipc.rs`
- Modify: `src/platform/unix/proc.rs` (`start_detached`), `src/host_base.rs`, `src/host_client.rs`, `src/host.rs` (tests through `by_os`), `src/bin/termurion-host.rs` (a `#[cfg(unix)] fn run()`), `src/app/semantic_ui.rs` (the Unix `start_detached` reason)

**Interfaces:**
- Produces: the P0 `platform::ipc` names, real on Unix: `Listener::{bind, renew, accept}`, `Pipe::{read, read_timeout, write_all, shutdown, server_pid, server_is_this_user}`, `connect`, `connect_owned`, `ConnectError`, `host_pipe_name`, `test_name`. A name holding a `/` is a socket path; a bare name (`test_name`'s) is `runtime_dir()?.join(name)`. `host_pipe_name()` = `<runtime>/host.sock`. `secret_pipe_name`, `url_pipe_name`, `own_peer`, `thread_peer`, `elevated`, `user_sid`, `check_peer` and the allow-all file calls stay `Unsupported` (their servers are not P1).
- Produces: `runtime_dir() -> Result<PathBuf, String>` over the pure `runtime_dir_from(xdg: Option<&Path>, tmp: &Path, euid: u32) -> PathBuf` (`$XDG_RUNTIME_DIR/termurion` when that folder is absolute and owned by the euid; else `<$TMPDIR or /tmp>/termurion-<euid>`), created with mode 0700, then `check_private(dir) -> Result<(), String>`: `lstat` says a directory, not a link, owner the euid, `mode & 0o077 == 0`; else `"<dir> is not a private folder of this user"`.
- Behavior: `bind` refuses a path longer than `sun_path` (104 on macOS, 108 on Linux) with `"the socket path <path> is too long"`; on `EADDRINUSE` it connects once: refused means stale, unlink and bind again; answered means `Err("another session host is already listening at <path>")` (the Windows first-instance rule).
