**Goal:** each pane draws with its own profile's fonts, exactly sized and shaped as iTerm2 draws them: bold and italic faces chosen by iTerm2's rules, ligatures only when the profile asks, anti-aliasing and thin strokes per profile, box drawing and Powerline glyphs drawn by Tandem to fill the cell, per-range Special Exceptions fonts, line height from the font's metrics, and Make Text Bigger and Smaller changing only the pane (or its broadcast group, or its profile) as iTerm2 does.

**Architecture:** the renderer (`src/render.rs`) stops having one font: it keeps a table of faces (`FaceKey` to `Face`: families, pixel size, spacing, cell, features, mask mode) and every `scene::TextRow` names its face; a pane's face comes from its own profile (`App::pane_face`), and a pane's cell size from its face (`App::pane_cell`), replacing the app-wide `font_offset`. Pure rules live in plain modules: `src/fonts.rs` (weight classes, bold face choice, line height, ligature and anti-alias decisions, the ligature blacklist), `src/boxdraw.rs` (which characters Tandem draws, iTerm2's path descriptions, rasterized masks with `zeno`), `src/powerline.rs` (the Powerline sets, the wide set, and every Powerline symbol drawn procedurally from its geometry), `src/font_table.rs` (Special Font Config's JSON and lookup). Text masks for non-anti-aliased and thin-stroke glyphs are filtered in a vendored `crates/glyphon` (patch 1); box drawing and Powerline glyphs reach the atlas as glyphon custom glyphs. The app side is `src/app/fonts_ui.rs` (new: faces, text size commands, broadcast and APS rules) and `src/special_exceptions_ui.rs` plus `src/app/special_exceptions_app.rs` (the editor window). Faces and cells are per pane (the Pane holds nothing new; faces derive from its profile) and the size commands are app-wide; no new field goes in `swap_live`.

**Tech Stack:** as milestone 11. No new crates in the tree: `glyphon` 0.12.0 becomes a vendored path crate (`crates/glyphon`, like `crates/alacritty_terminal`), `zeno` 0.3 (already in the tree through swash) becomes a direct dependency for path rasterization, `cosmic-text` 0.19's `FontFeatures`/`FeatureTag` and `CacheKeyFlags` are used as they are. No image or PDF asset from iTerm2 is converted or shipped: every Powerline symbol, the MIT PowerlineExtraSymbols included, is drawn procedurally (ruling 13m-o and the 13m-o plan review ruling).

### Decisions (each goes in `m13n-rulings.txt`)

- Each pane draws with its own profile's fonts through renderer faces; window chrome keeps the default profile's face. Cost: none known (iTerm2 does the same).
- The cell width stays the shaped advance, unrounded, as `set_font_px` already argues; only the height takes iTerm2's integer rule. Cost: a cell may be a fraction of a pixel narrower than iTerm2's.
- Fake bold is a second copy one physical pixel right. Cost: none known.
- NSFontManager weight classes are mapped from CSS weights by the table in `ns_weight`. Cost: a family with unusual weights may pick a different bold than on macOS.
- Ligatures are turned off with OpenType features (`liga`, `clig`, `calt`, `dlig` at 0) instead of iTerm2's no-shaping fast path; shaping stays on for every script. Cost: a font whose ligatures are required (`rlig`) still joins, as it would in iTerm2's shaped path.
- Non-anti-aliased and thin-stroke text filter the glyph mask in a vendored glyphon (threshold at 128; alpha squared). Cost: one more vendored crate to re-patch on updates; thin strokes look lighter but not like macOS font smoothing.
- Box drawing and Powerline glyphs are glyphon custom glyphs rasterized with zeno; box drawing follows iTerm2's path descriptions, and every Powerline shape (iTerm2's images and PowerlineExtraSymbols alike) is drawn procedurally from its geometry, nothing converted from iTerm2's files (ruling 13m-o, one uniform approach, no license files). Cost: the flame, wave and lego shapes are close to, not identical with, the originals.
- `DisableCustomBoxDrawing` applies when faces rebuild, not only after a restart. Cost: none.
- Wide Powerline symbols overdraw the next cell; the grid keeps one cell each. Cost: the next cell's text is covered, as in iTerm2.
- A size change on a tmux pane applies to every pane of its tmux window. Cost: none (tmux sizes are shared).
- Restore Text and Session Size acts as Make Text Normal Size until 13f's window sizing lands. Cost: rows and columns are not restored yet.
- The Nerd Font bundle install is shown disabled. Cost: users install Nerd Fonts themselves.

### Pitfalls for the implementer

- A face is measured on the GPU thread through `FontSystem`; never measure in `pane_cell` (it only reads).
- Every place that turns pointer pixels into cells must use the pane's cell, or clicks land in the wrong column in a pane with another font.
- A tmux pane's grid size is tmux's; a new cell size changes its pixel rectangle need, never its rows and columns (implementer rules).
- Spans of different faces, ligature levels or mask modes must never merge.
- glyphon caches custom glyphs by id and size only: include the weight (light, heavy) in the id, never reuse an id for two shapes.
- `CacheKeyFlags::from_bits_retain` keeps Tandem's bits 8 and 9; `CacheKeyFlags::from_bits` would drop them.
- `set_session_values` refreshes every pane; `change_font_size` on a broadcast group should write all copies first and refresh once.
- The stock profile's anti-alias seeds must stay: removing them would make every new profile aliased.
