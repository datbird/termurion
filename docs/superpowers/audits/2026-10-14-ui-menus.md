**Report: iTerm2 code-built menus other than the terminal right-click menu, compared with Termurion.**

Most menus are complete, and many Termurion files cite the iTerm2 line they port. I checked titles by grepping `src`. The gaps are listed first.

## Gaps (iTerm2 file:line → Termurion → missing)

1. **Downloads and Uploads menus** (AD = `AppKit/iTermApplicationDelegate.m`:724-755, `FileTransfer/FileTransferManager.m`:270-318) → NONE.
   - Termurion saves OSC 1337 downloads (`app/files_ui.rs`) but has no transfer menus.
   - Missing: top-level "Downloads" and "Uploads" menus, "Clear All", and the per-transfer submenu "Stop", "Show in Finder", "Remove from List", "Open" (downloads only), "Get Info".
2. **Session > Triggers runtime items** (AD:4277-4298, `menuNeedsUpdate`) → NONE.
   - Missing: one checkable item per profile trigger, below a separator, calling `toggleTriggerEnabled:`.
   - Termurion has only the static commands (`app/triggers_ui.rs:296`). The status-bar Triggers menu does have per-trigger items.
3. **View > "Current Tab Color"** (AD:380-386, a swatch view added in code) → NONE.
   - Termurion's Tab Color picker (`app/menu.rs:553`) is only reachable from the tab context menu.
4. **Scripts menu Option-alternate** (`API/iTermScriptsMenuController.m`:1568) → `scripts.rs`.
   - Missing: alternate item "Reveal %@" (reveal the script).
5. **Profile list search-field menu** (`Settings/Profiles/ProfileListView.m`:412) → `profile_list_ui.rs`.
   - Missing: the "Tags" heading plus its per-tag items, and "Search Syntax Help".
   - Termurion has the tag sidebar and "Tags >" button but no search-field dropdown.
6. **Settings text-field context menu** (`Settings/PreferencePanel.m`:302-348, `iTermPrefsFieldEditor`) → NONE.
   - Missing: "Reset to %@" (or "Reset to Empty Default"), shown when the value differs from the default.
7. **Workgroup branch item in the session toolbar** (`iTermSessionToolbarView.swift`:929) → `app/workgroup_toolbar_ui.rs:362` (`View::Git`).
   - Termurion draws it but has no right-click handling.
   - Missing: "Copy" (the branch name). iTerm2 also drags the branch name out of this item.
8. **Triggers editor share menu** (`Settings/TriggerController.m`:1121-1137) → `settings_triggers.rs:627`, `trigger_file.rs:29`.
   - Missing: "Copy Trigger as URL to Clipboard".
   - "Export to File" is present.
9. **Unsaved-settings click menu** (`Settings/UserDefaultsUnsavedController.swift`:134) → NONE.
   - Missing: "Disable Loading Settings from URL", "Save Settings", "Save Settings Automatically", "Hide Unsaved Changes Notification".
   - This probably does not apply, since Termurion has no custom-prefs-folder or URL-load mode. Confirm that before building it.
10. **Companion status item menu** (`Companion/CompanionPresenceController.swift`:122) → NONE.
    - Missing: disabled header "Companion device connected" or "Companion device paired (not connected)", and "Companion Device Settings…".
    - Termurion only has the `pairCompanionDevice:` command (`commands.rs:97`).
