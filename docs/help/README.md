# Termurion Help

These pages describe what Termurion does on Windows. Open Settings with Ctrl+Shift+, . The app Shortcut Key (the key iTerm2 calls Cmd) defaults to Ctrl+Shift. You can change it to Win or Ctrl+Alt in Settings > Keys. Option is Alt.

## Pages

- [Badges](badges.md): a large label in the corner of a pane, such as the host name.
- [Captured Output](captured-output.md): collect matching lines in a Toolbelt tool and jump to them.
- [Claude Code](claude-code.md): per-tab status for Claude Code, plus a Claude Code workgroup.
- [Color Presets](color-presets.md): ready-made color schemes you can load into a profile.
- [Coprocesses](coprocesses.md): a program wired to a session's input and output.
- [Copy Mode](copy-mode.md): select and copy text from the keyboard.
- [Dynamic Profiles](dynamic-profiles.md): define profiles in JSON or property list files.
- [Inline Images](inline-images.md): show pictures in the terminal with imgcat, sixel, and kitty graphics.
- [Paste Bracketing](paste-bracketing.md): how Termurion marks pasted text for the shell.
- [Password Manager](password-manager.md): store and type passwords, with Credential Manager, LastPass, and others.
- [Python API](python-api.md): script Termurion with Python.
- [Python API Authentication](python-api-auth.md): how a script proves it may use the API.
- [Python API Security](python-api-security.md): what the API can do and how to keep it safe.
- [Scripting Fundamentals](scripting-fundamentals.md): scripts, functions, and interpolated strings.
- [Search Syntax](search-syntax.md): how to write a search in the find bar.
- [Shell Integration](shell-integration.md): marks, the current directory, and other shell features.
- [Smart Selection](smart-selection.md): rules that select and act on text you double-click.
- [SSH Integration](ssh-integration.md): ssh sessions with file download, upload, and reconnection.
- [Status Bar](status-bar.md): live information at the edge of a session.
- [tmux Integration](tmux-integration.md): use tmux sessions as native tabs and panes.
- [Triggers](triggers.md): run an action when text appears in the output.
- [Variables](variables.md): the session, window, and user variables you can read.
- [Web Browser](web-browser.md): browse web pages in a pane.
- [Workgroups](workgroups.md): start a set of related sessions with one command.
