# Milestone 7c acceptance checklist

Close any open Tandem window, then run `C:\Users\datbi\src\tandem\target\release\tandem.exe`.
Cmd is the Win key and Option is Alt. Mark each line pass or fail.

| # | Check | Result |
|---|---|---|
| 1 | Open two windows; in one, split a tab three ways and `cd` somewhere in each pane (with shell integration). Window > Arrangements > Save Window Arrangement (Win+Shift+S): the name reads "Arrangement (<date>)". OK saves it. | |
| 2 | Save again with the same name: "Replace Existing Saved Window Arrangement?" Yes replaces, No keeps the old one. | |
| 3 | Close everything but one window. Window > Arrangements > Restore Window Arrangement > the saved name: both windows come back with the same tabs, splits (same shares), and folders. | |
| 4 | Restore Window Arrangement as Tabs: every saved tab opens in the current window. | |
| 5 | Save Current Window as Arrangement (Alt+Win+Shift+S) saves only this window. | |
| 6 | In the save dialog choose "Save to File with Contents...": a file saves; Load Arrangement from File opens it with each pane's old text above the new prompt. | |
| 7 | Download or copy a .itermarrangement from the internet (so Windows marks it): Load Arrangement from File asks `Open the arrangement "..."?` listing any custom commands; No opens nothing. | |
| 8 | An iTerm2 arrangement file from a Mac (with a three-way split) opens with the same panes. | |
| 9 | Settings > Arrangements: the list with "(default)" on the first saved; Set Default, Rename, and "-" work; the preview shows the windows and the selected tab's panes. Restore submenus follow the changes. | |
| 10 | Settings > Arrangements > pick a profile > Change Profile in Arrangement, then restore it: every pane uses that profile. | |
| 11 | Delete the profile an arrangement uses, restore: the panes use the default profile and a banner says so. | |
| 12 | Settings > General > Startup > "Open default window arrangement", restart Tandem: the default arrangement opens. | |
| 13 | Shell > Duplicate Window on a window with splits: the copy has the same splits, profiles, and folders. | |
