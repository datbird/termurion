# Milestone 12e acceptance checklist

Build a release binary (`scripts/xt build --release`). Close any open Tandem window, copy
`tandem.exe`, `tandem-host.exe`, `tandem-git.exe`, `conpty.dll`, and `OpenConsole.exe` from
`C:\Users\datbi\src\tandem\target\release\` together, then run `tandem.exe`.

Setup: 12a's "Enable generative AI features" on and an API key for one provider (Settings > AI; a
local Ollama model also works), the per-host consent answered Allow, a PowerShell session with
shell integration, and one run with AI off (row 1). 12c's and 12d's checklists are run with this
window. The tasks could not launch the GUI, so every row below is a behavior that was built and
tested only in pure code and by compile: dialog and wait windows, keyboard focus, drawing, the
spinner, popups, and the real typing and file writes. Mark each line pass or fail.
