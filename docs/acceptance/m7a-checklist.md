# Milestone 7a acceptance checklist

Close any open Tandem window, then run `C:\Users\datbi\src\tandem\target\release\tandem.exe`.
Cmd is the Win key and Option is Alt. Mark each line pass or fail.

| # | Check | Result |
|---|---|---|
| 1 | Shell > New Window (Win+N): a second window opens. Titles read "1. ..." and "2. ...". Typing goes to the window you click. | |
| 2 | Close window 1 (Win+Shift+W or its close box), then open another: the new one is "1." again (the lowest free number). | |
| 3 | Alt+Win+1 and Alt+Win+2 switch between the windows. A key bound to Next Window (or Previous Window) cycles them in number order and wraps. | |
| 4 | Shell > New Window with Current Profile (Alt+Win+Shift+N) opens a window with the focused session's profile. | |
| 5 | Profiles menu: every profile is listed. Picking one opens a tab; holding Alt while picking opens a window. Settings > Advanced > "Profiles menu opens new windows" swaps the two. | |
| 6 | A profile with "Always open in a new window, never a tab": New Tab with it opens a window instead. | |
| 7 | Window > Tab > Move Tab to New Window: the tab (with its running program) moves to a new window. Session > Move Session > Move Session to Window does the same for one split pane. | |
| 8 | Window > Arrange Windows > Merge All Windows: every other window's tabs join this window, and those windows close. | |
| 9 | Shell > Duplicate Window: a new window with a tab for each tab of this one. | |
| 10 | Window > Window Style: each of the 14 styles. Full-Width Top of Screen covers the top of the monitor with no title bar; Right of Screen docks right; Centered centers at the profile's columns and rows; Maximized fills the work area; Full Screen covers the monitor. Normal returns. | |
| 11 | Settings > Profiles > Window: set Style "Top of Screen (% of screen width)" with Height 30 percent, open a window with that profile: it opens docked at the top, 30 percent tall. | |
| 12 | Close a window after moving it, then open a window with the same profile: it opens at the same spot (New window placement "Remember the position ..."). With "Smart Window Placement", a second window avoids covering the first. | |
| 13 | Profile Screen "Screen with Cursor" (with two monitors): a new window opens on the monitor with the pointer. | |
| 14 | Window > Lock Layout: New Tab, split, and close pane beep and do nothing; resizing a divider still works. Lock Size: the window cannot be resized, and Lock Layout turns off. | |
| 15 | Window > Resize Window > Increase Height / Decrease Width: the window grows or shrinks by one row or column. | |
| 16 | Window > Edit Window Title "build": the title bar reads "1. build"; an empty title returns to the automatic one. Window > Tab > Edit Tab Title renames the tab. | |
| 17 | Window > Arrange Windows > Arrange Windows Horizontally with three windows: they sit side by side across the monitor. | |
| 18 | Click another app: Tandem's focused pane stays bright (its cursor turns hollow). Settings > Appearance > "Dim background windows" on: the whole window dims when in the background. | |
| 19 | A profile with "Hide after opening": its new window opens minimized. With "Lock window size automatically", it cannot be resized. | |
