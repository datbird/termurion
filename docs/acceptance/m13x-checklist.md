# Milestone 13x acceptance checklist

Build a release binary (`scripts/xt build --release`); the runtime rows and the window facts only mean something in release. Close any open Tandem window, copy `tandem.exe`, `tandem-host.exe`, `tandem-git.exe`, `conpty.dll` and `OpenConsole.exe` from `C:\Users\datbi\src\tandem\target\release\` together, then run `tandem.exe`. There is no `WebView2Loader.dll` to copy: the loader is linked into `tandem.exe` (ruling "static loader"), and a copy of that file beside it is simply ignored.

Run the rows on a machine with the WebView2 Runtime (the Evergreen runtime ships with current Windows 11 and Edge) in an interactive desktop session; the ignored runtime tests skip over SSH because that is session 0. For the upsell rows, hide the runtime from Tandem without uninstalling it: set Settings > Advanced > Web Browser > "Location of browser plugin" (`BrowserPluginPathHint`) to an empty folder you made (an empty folder is refused, so the browser reads as unavailable and the upsell shows); clear it afterwards. Setup for the rest: one Browser profile (Settings > Profiles > General > Profile type Browser), one Dev Null copy of it (Dev Null Mode on) and one with Instant Replay on; a local HTTP proxy (for example one listening on 127.0.0.1:8118) and Wireshark or `netsh trace` on this machine for the packet rows; a small local web server (for example `python -m http.server 8000`) holding the test pages named in the rows; a second Tandem window; AI set up (13a to 12f) with one provider for the chat icon rows; a script that calls RegisterTool and `async_open_popover` (Scripts > Manage; the Python runtime must be installed). Mark each line pass or fail; mark a row not applicable instead of fail when the tool itself is not installed on this machine.
