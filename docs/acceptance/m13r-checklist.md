# Milestone 13r acceptance checklist

Build a release binary (`scripts/xt build --release`), close any open Tandem window, copy `tandem.exe`,
`tandem-host.exe`, `tandem-git.exe`, `conpty.dll`, and `OpenConsole.exe` from
`C:\Users\datbi\src\tandem\target\release\` together, then run `tandem.exe`. Nothing of 13r was checked on screen during
the build. Mark each line pass or fail. Where a row says refused, the banner names the refusal and nothing starts.
