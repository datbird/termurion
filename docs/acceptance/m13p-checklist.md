Kept iTerm2 quirks and rulings a person can see (all in `docs/superpowers/rulings/m13p-rulings.txt`):

- The Windows locale is guessed from the user's languages and region; the picker lists each Windows locale as `ll_CC.UTF-8` and `ll_CC`; the start-time prompt does not hold the shell (the first session runs with `LC_CTYPE`, the answer applies to later sessions).
- `TERMINFO_DIRS` is for WSL only; MSYS2 and Cygwin get none. Load Shell Integration Automatically covers PowerShell only; bash, zsh and fish in WSL come with milestone 14.
- Initial Text ends with Enter as a CR and is never typed for SSH before login, git windows, orchestration, the REPL or `ssh:` links.
- The offscreen band shows no mark flash, blends its outline in sRGB and never appears over the alternate screen.
- Progress bars are inline and in tab cells only; the tab cell's bar needs more than one tab and a shown tab bar.
- A job name from tmux or a remote host loses control and bidirectional characters at the source (`session.jobName` in a status bar, badge or title shows it clean).
