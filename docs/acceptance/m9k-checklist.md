# Milestone 9k acceptance checklist

Close any open Tandem window. Copy `tandem.exe`, `tandem-host.exe`, `tandem-git.exe`,
`conpty.dll`, and `OpenConsole.exe` from `C:\Users\datbi\src\tandem\target\release\` together,
then run `tandem.exe`.

Setup: install shell integration in the PowerShell session (milestone 4a). On the profile you use,
add a Capture Output trigger matching `error` (Prefs > Profiles > Advanced > Triggers > Capture
Output; leave its "Coprocess to run on activation" field with something simple, like `echo %1`, so
a captured entry has a command to run later). Open two tabs and give each a different OSC 21337
status, for example `printf '\e]21337;status=Working;indicator=#ffa500\a'` in one and
`printf '\e]21337;status=Idle\a'` in the other, so Session Status has rows to sort. Start a
long-running child process in a pane (for example `ping -t localhost`, or a `while ($true) {
Start-Sleep 1 }` loop) for the Jobs tool. In Settings > Profiles create a second profile besides
Default. Place a named mark in a pane (Edit > Mark, or a Set Named Mark trigger). In Settings >
Shortcuts add a snippet and an action. With the toolbelt shown and a couple of tools on, save a
window arrangement (Window > Save Window Arrangement). None of this has been checked on a real
screen before this pass (every task deferred launching the GUI on EXTREME, since the rules forbid
it while the machine may be in use), so this pass is the first look. Mark each line pass or fail.
