# Milestone 12d acceptance checklist

Build a release binary (`scripts/xt build --release`). Close any open Tandem window, copy
`tandem.exe`, `tandem-host.exe`, `tandem-git.exe`, `conpty.dll`, and `OpenConsole.exe` from
`C:\Users\datbi\src\tandem\target\release\` together, then run `tandem.exe`.

Setup: an API key for one provider (Settings > AI, from 12a; a local Ollama model also works),
"Enable generative AI features" on, and the per-host consent answered Allow. Open a window with two
panes; the second pane is a PowerShell session so a command can be run and linked. Rows 1 to 63 were
written by the tasks that cannot test their code without a window (Tasks 1 to 10); rows 64 to 78
are the by-function rows Task 11 adds. 12c's checklist (`docs/acceptance/m12c-checklist.md`) is run
with this window: it names the buttons Stop, Cancel and Send Automatically by what they do. Mark each
line pass or fail.
