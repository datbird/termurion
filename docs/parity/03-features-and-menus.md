# iTerm2 features and menus

Sources used: `~/gitrepos/iterm2-ref/sources/MainMenu/Base.lproj/MainMenu.xib` for every menu command, and `sources/VT100/VT100Terminal.m` plus related parser files (`VT100SixelParser.m`, `InlineImages/KittyImageCommand.swift`, `Keyboard/iTermModernKeyMapper.swift`, `DragAndDrop/KittyDnD*.swift`) for escape sequences. Subsystem behavior comes from reading the matching source files directly: `TmuxController.m`, `TmuxGateway.m`, the shell integration scripts and utilities, `iTermStatusBar*Component*`, `Tool*.m`/`Tool*.swift`, the trigger action classes, `PasswordManager*`, `Composer*`, `FindViewController`/`iTermFindDriver`, `PasteSpecial*`/`PasteboardHistory*`, `OpenQuickly*`, `Arrangement*`, hotkey window classes, `iTermAI`/`AILiveHarness`, and `proto/api.proto`.
