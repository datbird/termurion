# iTerm2 global settings

This inventory covers iTerm2's application-wide (non-profile) settings: the General, Appearance, Keys, Pointer, Arrangements, and Advanced tabs of the Preferences window. It was built from sources/Settings/iTermPreferences.h and .m (kPreferenceKey* constants and their defaults), sources/Settings/iTermAdvancedSettingsModel.m (the DEFINE_BOOL/INT/FLOAT/STRING/INT_ENUM macros behind the Advanced tab), sources/Settings/GeneralPreferencesViewController.m, AppearancePreferencesViewController.m, KeysPreferencesViewController.m, PointerPreferencesViewController.m, PointerPrefsController.m/.h, iTermKeyBindingAction.h/.m, WindowArrangements.h, and the shared sources/Settings/Base.lproj/PreferencePanel.xib, which gives the exact sub-tab layout and control labels.

Tandem is a Windows terminal in Rust aiming for one-to-one parity with iTerm2. Its settings window has the General, Appearance, Keys, Shortcuts, Pointer, Arrangements and Advanced pages, and the global settings are stored in `%APPDATA%\Tandem\settings.toml`. Each row's status is kept current as milestones land: have where Tandem offers the setting and behaves as iTerm2 does, partial where Tandem's behavior covers only part of what the setting controls, and missing where it has neither. The counts per milestone are in 00-roadmap.md.

## Advanced

The Advanced tab is a single long searchable list of hundreds of individually named settings, each declared with a DEFINE_BOOL / DEFINE_INT / DEFINE_INT_ENUM / DEFINE_FLOAT / DEFINE_STRING macro in iTermAdvancedSettingsModel.m. Since milestone 13a, Settings > Advanced is iTerm2's searchable pane: every row the schema carries, grouped under iTerm2's 19 categories in Finder order with bold headers, a search field matching every typed word in the description or category, "Show only non-default values", and each value edited as iTerm2 does (No/Yes, Unspecified/No/Yes, a list, a number, a text). A row's status below says whether the behavior the setting controls exists (have), partly exists (partial) or does not exist yet (missing); a key iTerm2 defines but never reads is stored and shown and does nothing (have, ruling R2).
